# 🗺️ DevAtlas Roadmap

> A structured path from zero to full-stack developer. Follow the books in order — each one builds on the last.

Legend: 🟢 Beginner  🟡 Intermediate  🔴 Advanced &nbsp;|&nbsp; ⏱️ = estimated time if studying ~1–2 hrs/day

---

## Phase 1 — Foundations (🟢 Beginner) — ⏱️ 2–3 weeks

- [ ] **Book 01 — Foundations**
  - Computer Fundamentals
  - Operating Systems
  - Internet Fundamentals
  - How the Web Works
  - Developer Environment Setup
  - Command Line
  - Git Basics
  - Problem Solving / CS Thinking

**Milestone project:** None yet — this book is pure groundwork. Checkpoint: you can explain client-server communication, navigate a terminal, and make your first Git commit.

---

## Phase 2 — Core Web (🟢 Beginner → 🟡 Intermediate) — ⏱️ 6–8 weeks

- [ ] **Book 02 — HTML** — semantic structure, forms, accessibility basics
- [ ] **Book 03 — CSS** — box model, flexbox, grid, responsive design, animations
- [ ] **Book 04 — JavaScript** — syntax, DOM, events, async/await, fetch, ES6+
- [ ] **Book 05 — Bootstrap** — component-based rapid UI building
- [ ] **Book 06 — Tailwind CSS** — utility-first styling, design systems
- [ ] **Book 07 — Git & GitHub** — branching, PRs, collaboration workflows

**Milestone project:** A fully responsive, interactive static website (portfolio or landing page) built with HTML/CSS/JS, styled with Tailwind, version-controlled on GitHub.

---

## Phase 3 — Modern Frontend (🟡 Intermediate) — ⏱️ 6–8 weeks

- [ ] **Book 08 — TypeScript** — types, interfaces, generics, migrating JS → TS
- [ ] **Book 09 — React** — components, hooks, state management, routing
- [ ] **Book 10 — Next.js** — SSR/SSG, App Router, API routes, deployment

**Milestone project:** A multi-page React/Next.js app (e.g., a blog or dashboard) consuming a public API, written in TypeScript, deployed live (Vercel).

---

## Phase 4 — Backend & Databases (🟡 Intermediate → 🔴 Advanced) — ⏱️ 6–8 weeks

- [ ] **Book 11 — Node.js** — runtime, modules, event loop, npm ecosystem
- [ ] **Book 12 — Express.js** — REST APIs, middleware, auth, error handling
- [ ] **Book 13 — MongoDB** — NoSQL modeling, Mongoose, aggregation
- [ ] **Book 14 — SQL** — relational modeling, joins, PostgreSQL/MySQL basics

**Milestone project:** A REST API with authentication (JWT), connected to both a SQL and a NoSQL database, documented and tested.

---

## Phase 5 — Full Stack Integration (🔴 Advanced) — ⏱️ 4–6 weeks

- [ ] **Book 15 — Full Stack Development**
  - Connecting frontend (Next.js) to backend (Express/Node)
  - Authentication & authorization end-to-end
  - Deployment (Vercel/Render/Railway/Docker basics)
  - Testing (unit + integration)
  - Performance & security basics
  - System design fundamentals for web apps

**Capstone project:** A complete full-stack application — e.g., a social platform, e-commerce store, or SaaS tool — built solo or with contributors, deployed publicly, with a polished README, tests, and CI.

---

## 📌 How to Use This Roadmap

1. Don't skip Book 01 even if you've coded before — it fills real gaps.
2. Each book should end with: a **project**, a **quiz**, and **interview questions** (see `templates/`).
3. Track your progress by checking boxes above and updating your fork.
4. Don't rush Phase 3–4 — they're where most learners plateau. Build small projects constantly, not just at milestones.
5. Optional detours (add anytime after Phase 3): testing frameworks (Jest/Vitest), Docker, CI/CD, GraphQL, Redux/Zustand, System Design.
