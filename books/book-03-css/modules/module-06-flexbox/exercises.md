# Exercise Set — Flexbox

## Easy
- [ ] Turn a `<div>` containing three child `<div>`s into a flex row with `display: flex`.
- [ ] Center a single child both horizontally and vertically inside a full-height container.
- [ ] Write a nav bar with a logo on the left and links on the right using `justify-content: space-between`.
- [ ] Give three sibling elements `flex: 1` so they share space equally.

---

## Medium
- [ ] Build a fixed-width sidebar (250px) next to a fluid main content area using `flex: 0 0 250px` and `flex: 1`.
- [ ] Build a responsive card grid that wraps onto new lines using `flex-wrap: wrap` and `gap`.
- [ ] Explain the difference between `align-items` and `align-content`, and when `align-content` actually has any visible effect.
- [ ] Use `order` to visually move one item to the front of a row without changing its HTML position, and explain the accessibility caveat.

---

## Hard
- [ ] Build a sticky footer layout using `flex-direction: column`, `min-height: 100vh`, and `flex: 1` on the main content area.
- [ ] Given two items with `flex-grow: 1` and `flex-grow: 2`, explain exactly how extra space is distributed between them.
- [ ] Build a complete small page combining at least 3 patterns from Lesson 04 (e.g., nav bar + sidebar layout + sticky footer).
- [ ] Explain why Flexbox is described as "one-dimensional," and give an example layout need better suited to Grid instead.

---

## Bonus
- [ ] Research the difference between `flex-basis: 0` and `flex-basis: auto` in more depth, and explain how it affects `flex: 1` vs `flex: auto`.
