# Interview Questions — Flexbox

## Beginner
- What CSS declaration activates Flexbox on a container?
- What is the "main axis," and what's its default direction?
- What does `justify-content: center` do?
- What's the difference between `flex-grow` and `flex-shrink`?

## Intermediate
- What does the `flex: 1` shorthand actually set, and why is it so commonly used?
- What's the difference between `align-items` and `align-content`?
- How would you center content both horizontally and vertically using Flexbox?
- What accessibility caveat applies to the `order` property?

## Advanced
- Explain how `flex-direction: column` changes the meaning of `justify-content` and `align-items`.
- Walk through building a sticky footer layout using Flexbox, explaining each property's role.
- Given two flex items with `flex-grow: 1` and `flex-grow: 3`, explain precisely how leftover space is distributed.
- Why is Flexbox described as one-dimensional, and when would Grid be the more appropriate choice instead?
