# Module 06: Flexbox

> **Book:** Book 03 — CSS
> **Module:** 06 of Book 03

---

## 📌 Module Overview

Flexbox solves the real, everyday layout problems Module 05 exposed — centering, even distribution, flexible rows/columns. This module covers the main/cross axis mental model, every container and item property, and the handful of patterns (centering, nav bars, sidebars, card grids, sticky footers) that cover the vast majority of real-world layout needs.

**Difficulty:** 🟡 Intermediate
**Estimated Time:** 8–10 hours (lessons + exercises)
**Prerequisites:** Module 05 — Positioning & Layout Fundamentals
