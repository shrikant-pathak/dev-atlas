# Module 12 — Advanced & Modern CSS

## Overview
This module covers the newest and most powerful tools in modern CSS: custom properties and computed values, container queries, `:has()` and other modern selectors, native CSS nesting, `@property` for animatable variables, accessibility patterns, and shape/masking techniques.

## Lessons
1. Custom Properties (CSS Variables)
2. calc(), clamp(), min(), max()
3. Container Queries
4. :has() and Modern Selectors
5. CSS Nesting
6. @property and Accessibility Patterns
7. shape-outside and Masking

## Prerequisites
- Module 01 — CSS Fundamentals (cascade & specificity)
- Module 04 — Selectors & Combinators
- Module 08 — Responsive Design
- Module 09 — Backgrounds, Borders & Visual Effects
- Module 11 — Transitions, Transforms & Animations

## What You'll Be Able to Build After This Module
- Themeable components using custom properties, including dark mode
- Dynamically computed, fluid values combining calc/min/max/clamp
- Components that adapt to their container, not just the viewport
- Conditional styling based on descendants using :has()
- Cleanly organized, natively nested stylesheets
- Smoothly animatable custom properties via @property
- Accessible, motion-respectful, keyboard-friendly interfaces
- Custom-shaped elements and gradient-based fade masks
