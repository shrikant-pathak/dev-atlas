# Module 12 Interview Questions — Advanced & Modern CSS

1. What's the key behavioral difference between a CSS custom property and a Sass variable?
2. What does the fallback argument in `var(--name, fallback)` do?
3. Why is `calc()` needed to combine values like `100% - 250px`?
4. What's the mathematical relationship between `clamp()` and `min()`/`max()`?
5. What limitation of media queries do container queries solve?
6. What CSS property must be set before `@container` can target an element's descendants?
7. What capability did `:has()` give CSS that it never had before?
8. What's the difference between `:is()` and `:where()`?
9. What does plain nesting (without `&`) imply about the relationship between a parent and child rule?
10. Why is deep CSS nesting (4+ levels) generally discouraged?
11. Why can't a plain, unregistered custom property be smoothly animated, and what solves this?
12. Why does the visually-hidden CSS pattern avoid `display: none`?
13. What does `prefers-reduced-motion: reduce` detect, and why does it matter?
14. What's the difference between what `shape-outside` and `clip-path` each affect?
15. How does `mask-image` with a gradient produce a fade effect?
