# Module 08 Interview Questions — Responsive Design

1. What does the viewport meta tag do, and why is it essential for responsive design on mobile devices?
2. Explain the difference between `min-width` and `max-width` media queries.
3. What is mobile-first CSS, and why has it become the industry standard?
4. Walk through how you'd choose breakpoints for a real project.
5. What is `clamp()`, and what are its three arguments?
6. Why is `clamp(1rem, 4vw, 3rem)` generally safer than just using `font-size: 4vw`?
7. What CSS makes an image scale down safely inside a responsive container?
8. What problem does `srcset` solve, and how does it differ from what `<picture>` is used for?
9. What is `aspect-ratio`, and what problem does it solve that relates to Cumulative Layout Shift?
10. What was the common workaround for fixed aspect ratios before the `aspect-ratio` property existed?
11. How would you build a perfectly circular avatar of any size using `aspect-ratio`?
12. How does `prefers-color-scheme` work, and what problem does it solve without JavaScript?
13. What issues can arise from mixing `min-width` and `max-width` queries carelessly in the same stylesheet?
14. How would you combine `aspect-ratio` and `object-fit` for a responsive image?
