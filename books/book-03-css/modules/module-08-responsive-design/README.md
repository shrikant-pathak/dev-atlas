# Module 08 — Responsive Design

## Overview
This module covers how to make layouts genuinely adapt across the full range of real-world screen sizes — from media queries and the viewport meta tag through mobile-first strategy, fluid typography, responsive images/video, and the modern `aspect-ratio` property.

## Lessons
1. Media Queries (& the Viewport Meta Tag)
2. Mobile-First Approach
3. Responsive Typography
4. Responsive Images & Video
5. aspect-ratio

## Prerequisites
- Module 05 — Positioning & Layout Fundamentals
- Module 06 — Flexbox
- Module 07 — CSS Grid

## What You'll Be Able to Build After This Module
- Pages that adapt correctly from phone to ultrawide monitor
- Mobile-first stylesheets structured the way modern teams actually write CSS
- Typography that scales smoothly instead of jumping at breakpoints
- Images and video that load efficiently and look correct at every screen size
- Media and UI elements that hold a fixed ratio without layout shift
