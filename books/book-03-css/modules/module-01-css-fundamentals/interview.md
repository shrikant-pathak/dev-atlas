# Interview Questions — CSS Fundamentals

## Beginner
- What is CSS, and what is it NOT responsible for?
- What are the three ways to add CSS to an HTML page?
- What's the difference between a class selector and an ID selector?
- What character is used for CSS comments?

## Intermediate
- Why is external CSS considered the professional standard over inline or internal CSS?
- Explain the specificity weight of an ID selector versus a class selector.
- What happens when two CSS rules have identical specificity?
- Name two properties that inherit by default, and two that don't.

## Advanced
- Walk through how you'd debug a CSS rule that "isn't working" — what would you check, in order?
- Explain the full priority order of the cascade: importance, specificity, and source order.
- Why does inline CSS have such high specificity, and why is that considered a downside in practice?
- If a developer insists on using ID selectors for all styling, what would you explain to them about the long-term maintainability tradeoffs?
