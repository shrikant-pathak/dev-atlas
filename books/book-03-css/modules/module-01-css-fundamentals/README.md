# Module 01: CSS Fundamentals

> **Book:** Book 03 — CSS
> **Module:** 01 of Book 03

---

## 📌 Module Overview

This is where you start making your HTML actually look like something. This module covers what CSS is, its exact syntax, all three ways to connect it to HTML (and why external is the professional standard), fundamental selectors, and — most importantly — the cascade, specificity, and inheritance mechanisms that explain nearly every "why isn't my CSS working" moment you'll ever hit.

**Difficulty:** ⭐ Beginner
**Estimated Time:** 6–8 hours (lessons + exercises)
**Prerequisites:** Book 02 — HTML (all modules)
