# Exercise Set — CSS Fundamentals

## Easy
- [ ] Write a CSS rule making all `<h2>` elements dark green.
- [ ] Write a class selector `.card` that adds a light gray background.
- [ ] Link an external stylesheet called `main.css` to an HTML page.
- [ ] Write a comment explaining what a CSS rule does.

---

## Medium
- [ ] Given `<p class="note" id="alert">Text</p>` and three conflicting rules (`p`, `.note`, `#alert`) each setting a different `color`, determine which color wins and explain why.
- [ ] Write a single CSS rule applying the same font-family to `h1`, `h2`, and `h3` at once.
- [ ] Explain why inline styles are generally discouraged, using at least two reasons from Lesson 03.
- [ ] Write a rule using the universal selector to reset margin and padding to 0.

---

## Hard
- [ ] Calculate the specificity of `#main .card p.intro` step by step, showing your math.
- [ ] Given two rules with identical specificity targeting the same element, explain exactly which one wins and why.
- [ ] Explain why `color` inherits by default but `border` does not, using the reasoning from Lesson 05.
- [ ] Build a small HTML page styled entirely with internal CSS, then refactor it to use external CSS instead, explaining what changed and why it's better practice.

---

## Bonus
- [ ] Research the CSS Reset vs. Normalize.css approaches (not covered in this lesson) and explain, in your own words, the difference between them.
