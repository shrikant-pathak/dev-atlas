# Exercise Set — Positioning & Layout Fundamentals

## Easy
- [ ] Explain the difference between `display: none` and `visibility: hidden` with a concrete example.
- [ ] Write CSS positioning a badge in the top-right corner of a card using `position: relative` (parent) and `position: absolute` (child).
- [ ] Write a rule making an image responsive using `max-width: 100%` and `height: auto`.
- [ ] Write a `position: fixed` header that stays at the top while scrolling.

---

## Medium
- [ ] Explain why an absolutely positioned element sometimes jumps to the top of the entire page, and how to fix it.
- [ ] Build a sticky table header using `position: sticky`.
- [ ] Explain why a container with only floated children collapses to zero height, and write the clearfix fix.
- [ ] Write a rule using `overflow: hidden` combined with `border-radius` to clip a child image to a circular avatar shape.

---

## Hard
- [ ] Given a deeply nested element with `z-index: 9999` that still won't appear above a sibling element, explain the likely stacking-context cause.
- [ ] Build a horizontal row of same-sized nav buttons using `inline-block`, and explain how you'd avoid the whitespace-gap quirk.
- [ ] Build a responsive container: fluid width, capped max-width, centered, with `box-sizing: border-box` applied correctly.
- [ ] Explain the difference between `overflow: scroll` and `overflow: auto`, and when each is more user-friendly.

---

## Bonus
- [ ] Research `position: sticky`'s known limitation with `overflow: hidden` on an ancestor (not covered in this module) and explain what breaks.
