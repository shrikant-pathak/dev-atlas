# Module 05: Positioning & Layout Fundamentals

> **Book:** Book 03 — CSS
> **Module:** 05 of Book 03

---

## 📌 Module Overview

This module covers CSS's core layout-control tools before Flexbox and Grid: the `display` property, `position` and its positioning-context mental model, the genuinely confusing `z-index`/stacking-context relationship, overflow handling, float's legacy role, inline-block, and the max/min-width/height constraints that underpin responsive design.

**Difficulty:** 🟡 Intermediate
**Estimated Time:** 10–12 hours (lessons + exercises)
**Prerequisites:** Module 04 — Selectors & Combinators
