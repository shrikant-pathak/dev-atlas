# Module 10 Exercises — Practical UI Components & Patterns

## Lesson 01 — Navigation Bars
1. Build a sticky navbar with a brand on the left and links on the right.
2. Add a media query that hides the links and shows a hamburger icon below 700px.

## Lesson 02 — Dropdowns & Tooltips
3. Build a CSS-only dropdown menu that opens on hover.
4. Add `:focus-within` so keyboard users can also open the dropdown.
5. Build a tooltip that pulls its text from a `data-tooltip` attribute.

## Lesson 03 — Buttons Styling
6. Build a button with distinct `:hover`, `:active`, `:focus-visible`, and `:disabled` states.
7. Build primary, secondary, and outline button variants sharing one base class.

## Lesson 04 — Image Gallery & Sprites
8. Build a responsive image gallery using `auto-fit` + `minmax()` with uniform square thumbnails.
9. Build a masonry-style gallery using `columns`.
10. Build a two-icon sprite system using a single background image and `background-position`.

## Lesson 05 — Pagination & Multi-Column
11. Build a pagination bar with an active page and a disabled "Prev" button.
12. Build a two-column article layout using `columns`, with a heading that never separates from its paragraph.

## Lesson 06 — Forms Styling
13. Style a text input with a custom focus ring using `box-shadow`.
14. Build a custom-styled checkbox using the "hide and replace" technique.
15. Add `:invalid`/`:valid` feedback to a required email field, avoiding a red border on page load.

## Lesson 07 — Image Modal / Lightbox
16. Build a CSS-only modal using `:target` that opens when a thumbnail is clicked.
17. Add a dimmed backdrop and a close link that clears the URL fragment.
18. Add a fade transition to the modal using `opacity`/`visibility` instead of `display`.
