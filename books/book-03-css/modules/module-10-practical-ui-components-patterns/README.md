# Module 10 — Practical UI Components & Patterns

## Overview
This module assembles everything from Modules 01–09 into complete, real-world UI components: navbars, dropdowns, tooltips, buttons, image galleries, pagination, multi-column text, forms, and a fully CSS-only modal/lightbox.

## Lessons
1. Navigation Bars
2. Dropdowns & Tooltips
3. Buttons Styling
4. Image Gallery & Sprites
5. Pagination & Multi-Column
6. Forms Styling
7. Image Modal / Lightbox

## Prerequisites
- Module 04 — Selectors & Combinators
- Module 05 — Positioning & Layout Fundamentals
- Module 06 — Flexbox
- Module 07 — CSS Grid
- Module 08 — Responsive Design
- Module 09 — Backgrounds, Borders & Visual Effects

## What You'll Be Able to Build After This Module
- Responsive, sticky navigation bars with a mobile collapse pattern
- CSS-only dropdowns and tooltips with accessible focus handling
- A complete, accessible button system with all interactive states
- Responsive and masonry-style image galleries
- Pagination controls and multi-column article layouts
- Custom-styled form inputs, checkboxes, and radios with validation feedback
- A fully CSS-only modal/lightbox gallery using `:target`
