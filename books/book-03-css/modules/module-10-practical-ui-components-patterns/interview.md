# Module 10 Interview Questions — Practical UI Components & Patterns

1. How would you build a responsive navbar that collapses into a mobile menu?
2. What's the difference between `position: sticky` and `position: fixed`?
3. How would you build a CSS-only dropdown, and what's its main accessibility limitation?
4. Why is `:focus-visible` preferred over plain `:focus` for button focus rings?
5. Name the four key interactive states a well-designed button should handle.
6. How would you build a responsive image gallery without media queries?
7. What was a CSS sprite sheet used for, and why is it less common today?
8. Why can't `<a>` tags use the native `disabled` HTML attribute, and what's the CSS workaround?
9. What does `columns: 3 250px` do?
10. Why is `opacity: 0` (rather than `display: none`) used to visually hide a real checkbox input in the "hide and replace" technique?
11. What does `:invalid:not(:placeholder-shown)` accomplish, and why is the `:not()` part necessary?
12. Explain how a CSS-only modal built with `:target` opens and closes without JavaScript.
13. Why can't `display` be used with `transition`, and what properties are used instead to fade an element in/out?
14. What does `attr(data-tooltip)` do inside a `content` value?
15. How would you prevent an image from being awkwardly split across two columns in a multi-column layout?
