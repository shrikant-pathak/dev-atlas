# Module 13 — CSS Architecture & Real-World Project

## Overview
This module closes Book 03 by shifting from individual techniques to how real, production CSS codebases are actually organized, named, and optimized — then applies everything from all 13 modules in a capstone project styling the Book 02 HTML portfolio.

## Lessons
1. Naming Conventions & BEM
2. Organizing Large Stylesheets
3. CSS Performance
4. Sass/SCSS Preview
5. Capstone Project — Styling Your HTML Portfolio

## Prerequisites
- All of Book 03, Modules 01–12
- Book 02 — HTML (the portfolio project being styled)

## What You'll Be Able to Build After This Module
- Collision-resistant, self-documenting CSS using BEM naming
- A scalable, component-scoped stylesheet architecture
- Performance-conscious CSS that avoids unnecessary layout/paint work
- A working understanding of Sass, for reading and contributing to existing codebases
- A complete, polished, responsive, accessible personal portfolio site
