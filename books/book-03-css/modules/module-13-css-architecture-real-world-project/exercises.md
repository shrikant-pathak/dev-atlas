# Module 13 Exercises — CSS Architecture & Real-World Project

## Lesson 01 — Naming Conventions & BEM
1. Rewrite a set of deeply-nested selectors (`.page .sidebar .widget h3`) as flat BEM class names.
2. Build a `.btn` block with two elements and two modifiers using strict BEM syntax.

## Lesson 02 — Organizing Large Stylesheets
3. Sketch a folder structure for a mid-size project with a navbar, footer, three page types, and a design system of buttons/cards/forms.
4. Explain, using the ITCSS model, why a utility class like `.text-center` should load after component styles rather than before.

## Lesson 03 — CSS Performance
5. Identify which of two hover effects (one animating `box-shadow` directly, one animating `opacity` on a pseudo-element layer) is more compositor-friendly, and explain why.
6. Add `content-visibility: auto` and `contain-intrinsic-size` to a long list of off-screen items.

## Lesson 04 — Sass/SCSS Preview
7. Convert a Sass `$variable`-based color system into native CSS custom properties.
8. Write a Sass mixin for a card component, then explain what native CSS feature (if any) could replace it, and what it couldn't.

## Lesson 05 — Capstone Project
9. Complete the full Required Techniques Checklist against your Book 02 HTML portfolio.
10. Perform the Final Review Pass (performance + accessibility) and document at least two changes you made as a result.
