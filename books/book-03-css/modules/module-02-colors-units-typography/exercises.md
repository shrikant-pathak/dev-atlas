# Exercise Set — Colors, Units & Typography

## Easy
- [ ] Write three CSS rules setting the same blue color using named, hex, and RGB formats.
- [ ] Convert `#ff0000` to shorthand hex notation.
- [ ] Write a font stack for body text ending in a proper generic fallback.
- [ ] Set a paragraph's `line-height` to a sensible readable value.

---

## Medium
- [ ] Write an RGBA color that's 40% opaque black, and explain a real use case for it.
- [ ] Explain the compounding problem with `em` using a 3-level nested example, then rewrite it using `rem` to fix it.
- [ ] Link a Google Font of your choice and apply it to your page's headings.
- [ ] Write a rule that removes the default underline from links, then restores it only on hover.

---

## Hard
- [ ] Write two HSL colors representing the same hue/saturation but different lightness values, and explain a real use case (like a button hover state).
- [ ] Write a complete `@font-face` rule self-hosting a `.woff2` font file, including `font-display: swap`.
- [ ] Build a small hero section using `100vh` and explain why `vh` is more appropriate here than a fixed pixel height.
- [ ] Add an icon to a button using two different approaches (e.g., an icon font AND an inline SVG) and compare the resulting HTML.

---

## Bonus
- [ ] Research the `ch` and `ex` CSS units (not covered in this module) and explain what each is relative to.
