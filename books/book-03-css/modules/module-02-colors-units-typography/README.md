# Module 02: Colors, Units & Typography

> **Book:** Book 03 — CSS
> **Module:** 02 of Book 03

---

## 📌 Module Overview

This module covers the visual building blocks you'll use in nearly every stylesheet: color formats (hex, RGB, HSL, and transparency), the full range of CSS units and when to use each, typography and font stacks, adding custom web fonts, core text styling properties, and how to add icons to a page.

**Difficulty:** ⭐ Beginner
**Estimated Time:** 7–9 hours (lessons + exercises)
**Prerequisites:** Module 01 — CSS Fundamentals
