# Module 11 — Transitions, Transforms & Animations

## Overview
This module covers how to add motion to CSS — simple state-based transitions, 2D and 3D transforms, full keyframe animation sequences, and the modern scroll-snap technique for scroll-driven UI.

## Lessons
1. CSS Transitions
2. 2D Transforms
3. 3D Transforms
4. Keyframe Animations
5. Scroll Snap

## Prerequisites
- Module 04 — Selectors & Combinators
- Module 05 — Positioning & Layout Fundamentals
- Module 06 — Flexbox
- Module 10 — Practical UI Components & Patterns

## What You'll Be Able to Build After This Module
- Smooth, polished hover and state-change effects using `transition`
- Moved, rotated, scaled, and skewed elements using 2D transforms
- Genuine depth effects and a working flip card using 3D transforms
- Custom multi-step animations (spinners, pulses, bounce-ins) using `@keyframes`
- Snapping carousels, full-screen sections, and galleries using scroll-snap
