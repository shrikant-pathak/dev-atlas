# Module 11 Quiz — Transitions, Transforms & Animations

1. Which two parts of the `transition` shorthand are required?
   a) Timing-function and delay
   b) Property and duration
   c) Delay and property
   d) Duration and timing-function

2. Why doesn't `transition: display 0.3s` work?
   a) `display` isn't a real property
   b) `display` has no meaningful in-between value to interpolate
   c) It requires `!important`
   d) It only works with `opacity`

3. Which transform function moves an element without affecting document layout?
   a) `margin()`
   b) `translate()`
   c) `top()`
   d) `float()`

4. What must be set for a 3D transform to render with visible depth?
   a) `z-index`
   b) `perspective`
   c) `overflow: hidden`
   d) `position: absolute`

5. What does `backface-visibility: hidden` do?
   a) Hides the element permanently
   b) Hides an element's back once it's rotated past 90 degrees
   c) Removes shadows
   d) Disables transforms entirely

6. What can `@keyframes` express that `transition` cannot?
   a) Color changes
   b) Multi-step sequences with intermediate states
   c) Hover effects
   d) Media queries

7. Which two properties are preferred for performant animation?
   a) `width` and `height`
   b) `top` and `left`
   c) `transform` and `opacity`
   d) `margin` and `padding`

8. What does `scroll-snap-type: x mandatory` do?
   a) Disables scrolling
   b) Forces horizontal scroll position to always land on a snap point
   c) Enables vertical snapping only
   d) Adds smooth scroll behavior automatically
