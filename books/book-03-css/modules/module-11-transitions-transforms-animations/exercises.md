# Module 11 Exercises — Transitions, Transforms & Animations

## Lesson 01 — CSS Transitions
1. Build a button whose background color and box-shadow both transition on hover, using two different durations.
2. Build a staggered list reveal using `transition-delay` and `:nth-child()`.

## Lesson 02 — 2D Transforms
3. Build a hover-lift card effect using `translateY()`.
4. Build a "+" icon that rotates into an "×" using `rotate(45deg)` and a toggled class.
5. Demonstrate that transform order matters by comparing `translate() rotate()` vs `rotate() translate()` on the same element.

## Lesson 03 — 3D Transforms
6. Build a rotating 3D box face using `rotateY()` and `perspective`.
7. Build a complete flip card with front/back faces using `backface-visibility` and `transform-style: preserve-3d`.

## Lesson 04 — Keyframe Animations
8. Build a `@keyframes` pulse animation and apply it on an infinite loop.
9. Build a "bounce-in" multi-step animation for a toast notification.
10. Build a CSS-only loading spinner using `@keyframes` and `rotate(360deg)`.

## Lesson 05 — Scroll Snap
11. Build a horizontal card carousel that snaps to center using `scroll-snap-type` and `scroll-snap-align`.
12. Build a full-screen vertical section scroller using `scroll-snap-type: y mandatory`.
13. Add `scroll-padding-top` to account for a sticky header in a snapping layout.
