# Module 09 Interview Questions — Backgrounds, Borders & Visual Effects

1. What's the difference between `background-size: cover` and `contain`?
2. How do you layer a gradient over a background image?
3. List all five values `box-shadow` can accept, in order.
4. What does the `inset` keyword do on a box-shadow?
5. Why does `text-overflow: ellipsis` require `overflow: hidden` and `white-space: nowrap` to work?
6. How would you create text filled with a gradient instead of a solid color?
7. What's the difference between `filter` and `backdrop-filter`?
8. What are the three pieces required to build a working CSS counter?
9. How would you produce multi-level numbering like "1.1", "1.2" using nested counters?
10. What's the key difference between fading an element with `opacity` and giving it a semi-transparent `rgba()` background?
11. Does `opacity: 0` remove an element from the page's layout flow? How does that differ from `display: none`?
12. What side effect does `opacity` below 1 have on stacking context?
13. When would you choose `rgba()` over `opacity`, and vice versa?
