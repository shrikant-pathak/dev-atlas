# Module 09 Quiz — Backgrounds, Borders & Visual Effects

1. Which value fills the element completely, cropping if necessary?
   a) `background-size: contain`
   b) `background-size: cover`
   c) `background-size: auto`
   d) `background-size: fit`

2. `box-shadow` accepts how many values total (including the optional one)?
   a) 3
   b) 4
   c) 5
   d) 6

3. `text-shadow` is missing which value compared to `box-shadow`?
   a) Color
   b) Offset-Y
   c) Spread-radius
   d) Blur-radius

4. Which three properties together create the "truncate with ellipsis" effect?
   a) `overflow`, `text-align`, `white-space`
   b) `white-space: nowrap`, `overflow: hidden`, `text-overflow: ellipsis`
   c) `text-overflow`, `word-break`, `display`
   d) `overflow-wrap`, `white-space`, `text-align`

5. `background-clip: text` combined with `color: transparent` is used to:
   a) Hide text completely
   b) Fill text with a background gradient or image
   c) Add a shadow to text
   d) Truncate long text

6. What does `backdrop-filter` affect?
   a) The element's own content
   b) Whatever is visible behind/through the element
   c) The page's scrollbar
   d) Only images, never other elements

7. Which CSS property increases a named counter by 1 each time a rule matches?
   a) `counter-reset`
   b) `counter()`
   c) `counter-increment`
   d) `content`

8. Fading an element with `opacity: 0.5` affects:
   a) Only its background color
   b) Only its text color
   c) The entire element and all of its children uniformly
   d) Nothing until combined with `rgba()`

<details><summary>Answer Key</summary>

1. b
2. c
3. c
4. b
5. b
6. b
7. c
8. c

</details>
