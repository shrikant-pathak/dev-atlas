# Module 09 Exercises — Backgrounds, Borders & Visual Effects

## Lesson 01 — Backgrounds & Gradients
1. Build a button with a linear gradient background going from one color to another.
2. Build a hero section with a photo background and a dark gradient overlay for text legibility.
3. Create a simple color wheel using a `conic-gradient`.

## Lesson 02 — box-shadow & text-shadow
4. Build a card with a soft, layered box-shadow (two shadows combined).
5. Build a "pressed" button state using `inset` box-shadow.
6. Add a legibility text-shadow to white text over a busy background image.

## Lesson 03 — Text Effects
7. Truncate a long paragraph to one line with an ellipsis using the three-property combo.
8. Create a heading with gradient-filled text using `background-clip: text`.
9. Build a frosted-glass navigation bar using `backdrop-filter: blur()`.

## Lesson 04 — CSS Counters
10. Build a custom-numbered list using `counter-reset`, `counter-increment`, and `counter()`, replacing the browser's default `<ol>` numbering.
11. Build a two-level nested outline (e.g., "1.1", "1.2", "2.1") using nested counters.

## Lesson 05 — Opacity
12. Build two boxes with black text on a black background — fade one using `opacity` and the other using `rgba()` — and compare what happens to the text in each.
13. Build a disabled button state using `opacity` and explain why `opacity: 0` isn't equivalent to `display: none`.
