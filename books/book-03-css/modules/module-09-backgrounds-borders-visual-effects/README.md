# Module 09 — Backgrounds, Borders & Visual Effects

## Overview
This module covers the visual polish layer of CSS — backgrounds and gradients, shadows, text effects like truncation and gradient text, automatic CSS counters, and the opacity property, including the common gotchas around each.

## Lessons
1. Backgrounds & Gradients
2. box-shadow & text-shadow
3. Text Effects
4. CSS Counters
5. Opacity

## Prerequisites
- Module 02 — Colors, Units & Typography
- Module 03 — The Box Model
- Module 04 — Selectors & Combinators
- Module 05 — Positioning & Layout Fundamentals

## What You'll Be Able to Build After This Module
- Gradient backgrounds, layered backgrounds, and gradient-filled text
- Raised/pressed card and button effects with box-shadow
- Frosted-glass panels and image filter effects
- Automatically numbered, multi-level outlines with CSS counters
- Correctly faded elements and disabled states using opacity
