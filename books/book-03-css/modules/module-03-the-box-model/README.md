# Module 03: The Box Model

> **Book:** Book 03 — CSS
> **Module:** 03 of Book 03

---

## 📌 Module Overview

Every HTML element is fundamentally a rectangular box — this module gives you complete, precise control over each layer of that box: content, padding, border, and margin, plus the `box-sizing` property that fixes CSS's most confusing default behavior. It closes with practical application: rounded corners, styling the lists/tables from Book 02, and preventing image distortion with `object-fit`.

**Difficulty:** ⭐ Beginner → 🟡 Intermediate
**Estimated Time:** 9–11 hours (lessons + exercises)
**Prerequisites:** Module 02 — Colors, Units & Typography
