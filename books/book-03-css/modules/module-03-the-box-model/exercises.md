# Exercise Set — The Box Model

## Easy
- [ ] Draw (describe in words) the four layers of the box model, from innermost to outermost.
- [ ] Write a box with `width: 200px`, `padding: 20px`, `border: 5px solid black`, and calculate its total rendered width under the default box model.
- [ ] Apply `box-sizing: border-box` to that same box and recalculate the total width.
- [ ] Write CSS turning a 100×100px square element into a perfect circle.

---

## Medium
- [ ] Given two stacked elements with `margin-bottom: 24px` and `margin-top: 16px`, determine the actual gap between them and explain why.
- [ ] Write a properly reset navigation list (`list-style-type`, `margin`, `padding`) for a horizontal nav bar.
- [ ] Style a table using `border-collapse`, zebra-striping, and row hover highlighting.
- [ ] Explain why removing the default focus outline without a replacement is an accessibility problem.

---

## Hard
- [ ] Build a card component using padding, border, border-radius, and `margin: 0 auto` to center it.
- [ ] Explain, using a concrete example, why applying `box-sizing: border-box` globally is considered near-universal best practice in modern CSS.
- [ ] Build an image gallery of fixed-size thumbnails using `object-fit: cover`, and explain what would go wrong without it.
- [ ] Style a `<dl>` glossary (from Book 02) with custom `::marker` styling on an accompanying `<ul>` list elsewhere on the same page.

---

## Bonus
- [ ] Research `border-image-slice` in more depth (only briefly covered in this module) and explain what the numeric value actually controls.
