# Module 04: Selectors & Combinators

> **Book:** Book 03 — CSS
> **Module:** 04 of Book 03

---

## 📌 Module Overview

Module 01 gave you basic selectors; this module gives you the full, precise vocabulary — pseudo-classes for state and structure, pseudo-elements for generated content, attribute selectors for flexible targeting, and combinators for describing relationships between elements. It closes by returning to specificity with genuinely complex selectors, and covers `!important` and the correct order for styling link states.

**Difficulty:** 🟡 Intermediate
**Estimated Time:** 9–11 hours (lessons + exercises)
**Prerequisites:** Module 03 — The Box Model
