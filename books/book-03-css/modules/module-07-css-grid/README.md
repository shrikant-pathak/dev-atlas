# Module 07 — CSS Grid

## Overview
This module covers CSS Grid — the two-dimensional layout system that complements Flexbox (Module 06) for building full page structures, card galleries, and any layout requiring simultaneous row and column control.

## Lessons
1. CSS Grid Intro
2. Grid Container Properties
3. Grid Item Properties
4. Grid Template Areas
5. Grid 12-Column Layout
6. CSS @supports

## Prerequisites
- Module 05 — Positioning & Layout Fundamentals
- Module 06 — Flexbox

## What You'll Be Able to Build After This Module
- Full-page layouts (header/sidebar/main/footer) with named grid areas
- Responsive card galleries with zero media queries (`auto-fit` + `minmax()`)
- Framework-style 12-column layouts without a CSS framework
- Layouts that degrade gracefully on older browsers via `@supports`
