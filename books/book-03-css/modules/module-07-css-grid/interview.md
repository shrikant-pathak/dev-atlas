# Module 07 Interview Questions — CSS Grid

1. What problem does CSS Grid solve that Flexbox doesn't?
2. What is the `fr` unit, and how does it differ from a percentage?
3. Explain the difference between `auto-fit` and `auto-fill`.
4. What does `minmax()` do, and why would you use it instead of a fixed pixel value?
5. Walk through what `grid-column: 2 / span 3` does.
6. What's the difference between `grid-template-areas` and line-based placement (`grid-column` / `grid-row`)? When would you choose one over the other?
7. Can Grid items overlap? How would you make that happen intentionally?
8. What's the difference between `justify-items` and `justify-content` on a grid container?
9. What does `@supports` test, and how does it differ from `@media`?
10. How would you build a responsive card gallery that adjusts its column count without writing a single media query?
11. Explain the "Holy Grail" layout and how named grid areas make it easier to build than historical approaches (floats, tables).
12. Why did the 12-column system become a common convention, and how would you implement it with CSS Grid?
13. In a real project, would you use Grid or Flexbox for a navbar with a logo on the left and links on the right? Why?
14. What happens to the contents of an `@supports` block when its condition evaluates to false?
15. How would you combine Grid and Flexbox in the same component, and why might that be the right call?
