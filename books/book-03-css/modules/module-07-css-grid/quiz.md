# Module 07 Quiz — CSS Grid

1. Which property activates CSS Grid on a container?
   a) `display: flex`
   b) `display: grid`
   c) `grid: true`
   d) `layout: grid`

2. What does the `fr` unit represent?
   a) A fixed pixel value
   b) A fraction of the available space
   c) A percentage of the viewport
   d) A font-relative unit

3. `repeat(auto-fit, minmax(200px, 1fr))` is most useful for:
   a) Fixed 2-column layouts
   b) Responsive layouts without media queries
   c) Overlapping grid items
   d) Feature detection

4. What is the correct order of values in the `grid-area` shorthand?
   a) column-start / row-start / column-end / row-end
   b) row-start / column-start / row-end / column-end
   c) row-start / row-end / column-start / column-end
   d) start / end / span / gap

5. Which character marks an intentionally empty cell in `grid-template-areas`?
   a) `#`
   b) `_`
   c) `.`
   d) `x`

6. What does `@supports (display: grid)` check?
   a) Whether the viewport is wide enough for Grid
   b) Whether the current browser can apply the `display: grid` declaration
   c) Whether Grid is faster than Flexbox
   d) Whether a media query matches

7. In a 12-column grid, `grid-column: span 4` produces a column that is:
   a) 4 pixels wide
   b) One third of the row width
   c) One quarter of the row width
   d) The full row width

8. `justify-items` (on the container) controls:
   a) Alignment of the whole grid within its container
   b) Alignment of each item within its own cell, along the row axis
   c) The gap between rows
   d) The number of columns

<details><summary>Answer Key</summary>

1. b
2. b
3. b
4. b
5. c
6. b
7. c
8. b

</details>
