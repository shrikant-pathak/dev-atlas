# 📘 Book 01: Foundations

> Learn the fundamental concepts of computers, the Internet, operating systems, developer tools, and problem-solving before starting web development.

---

## 📖 Overview

Every great software developer starts with strong fundamentals.

This book introduces the core concepts required before learning HTML, CSS, JavaScript, or any programming language. By understanding how computers work, how the Internet communicates, and how websites are delivered to users, you'll build a strong foundation that makes learning modern web development much easier.

Whether you're a complete beginner, a college student, or someone changing careers, this book is your starting point.

---

# 🎯 Learning Objectives

After completing this book, you will be able to:

- Explain what a computer is and how it works.
- Identify the major hardware components of a computer.
- Understand the role of CPUs, memory, storage, and motherboards.
- Explain the difference between hardware and software.
- Understand operating systems and their responsibilities.
- Explain how the Internet works.
- Describe how websites are delivered from servers to browsers.
- Set up a developer environment.
- Use the command line for basic tasks.
- Understand the basics of Git and version control.
- Apply basic problem-solving techniques.
