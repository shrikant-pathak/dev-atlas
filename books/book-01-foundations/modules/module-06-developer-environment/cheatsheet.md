# 📄 Cheat Sheet — Developer Environment

## VS Code Shortcuts

| Action | macOS | Windows/Linux |
|---|---|---|
| Command Palette | Cmd+Shift+P | Ctrl+Shift+P |
| Quick file open | Cmd+P | Ctrl+P |
| Toggle terminal | Cmd+` | Ctrl+` |
| Save | Cmd+S | Ctrl+S |
| Find in file | Cmd+F | Ctrl+F |
| Find in all files | Cmd+Shift+F | Ctrl+Shift+F |
| Multi-cursor | Option+Click | Alt+Click |

## Essential Extensions

| Extension | Purpose |
|---|---|
| Prettier | Auto-formats code |
| ESLint | Flags code errors/style issues |
| GitLens | Enhanced Git history/blame |
| Live Server | Local dev server with auto-reload |
| Path Intellisense | Autocompletes file paths |
| Auto Rename Tag | Syncs opening/closing HTML/JSX tags |

## Opening DevTools

| Browser Action | Shortcut |
|---|---|
| Open DevTools | Cmd+Option+I (macOS) / Ctrl+Shift+I (Win/Linux) |
| Quick open (F12) | F12 (most browsers) |

## DevTools Panels

| Panel | Purpose |
|---|---|
| Elements | Live-edit HTML/CSS |
| Console | Run JS, view logs/errors |
| Network | Inspect HTTP requests |
| Sources | Debug JS with breakpoints |
| Application | Cookies, storage, cache |
| Performance | Rendering performance analysis |

## Default Shells by OS

| OS | Default Shell |
|---|---|
| macOS | zsh |
| Linux | bash / zsh |
| Windows | PowerShell |

## Common Project Files

| File/Folder | Purpose |
|---|---|
| `README.md` | Project description and setup instructions |
| `package.json` | Dependencies, scripts, metadata (Node projects) |
| `.gitignore` | Files/folders excluded from Git |
| `src/` | Source code |
| `public/` / `assets/` | Static files (images, fonts) |
| `node_modules/` | Installed dependencies (never edited directly) |
| `.env` | Environment variables/secrets |
