# Exercise Set — Developer Environment

## Easy
- [ ] Open VS Code's Command Palette and use it to change your color theme.
- [ ] Install the Prettier extension and format an existing file using it.
- [ ] Open browser DevTools on any website and find its Console panel.
- [ ] Open VS Code's integrated terminal and run `pwd` to confirm it opened in your project folder.

---

## Medium
- [ ] Create a new project folder containing a `README.md`, a `.gitignore`, and a `src/` folder with an `index.html` inside it.
- [ ] In DevTools' Elements panel, temporarily change the text of a heading on any website and observe that it resets on refresh.
- [ ] Use the Console panel to run `console.log()` with a message of your choice, then use `document.body.style.backgroundColor` to change the page's background color live.
- [ ] Explain what `.gitignore` should contain for a typical Node.js project, and why.

---

## Hard
- [ ] Set a breakpoint in a script on a real website (using Sources panel) and step through its execution line by line.
- [ ] Compare organizing a project "by type" versus "by feature" — restructure a small example project both ways and note the tradeoffs you observe.
- [ ] Explain, from memory, at least 5 essential VS Code extensions and what each is used for.

---

## Bonus
- [ ] Research and try installing "Oh My Zsh" (or an equivalent) to customize your terminal prompt with useful information like your current Git branch.
