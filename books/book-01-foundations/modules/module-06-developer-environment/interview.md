# Interview Questions — Developer Environment

## Beginner
- What is VS Code, and why is it popular among web developers?
- What is an extension, and how do you install one?
- What are browser DevTools used for?
- What is a shell?

## Intermediate
- Name three essential VS Code extensions and explain what each does.
- Walk through a basic debugging workflow using DevTools' Elements, Console, and Sources panels.
- What is `.gitignore`, and why is it important for a project?
- What's the difference between VS Code's integrated terminal and a separate terminal application?

## Advanced
- Explain how you'd set and use a breakpoint to debug a JavaScript issue on a live website.
- Why might a team enforce consistent file structure conventions across a codebase, beyond personal preference?
- What's the difference between disabling and uninstalling a VS Code extension, and when would you choose each?
- Explain the role of `package.json` in a Node.js-based project (at a conceptual level, even before deep-diving into it in later books).
