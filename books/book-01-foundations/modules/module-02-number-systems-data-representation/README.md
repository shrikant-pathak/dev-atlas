## 📌 Module Overview

This module answers a question most developers never stop to ask: *how does a computer, which only understands electrical on/off states, end up displaying text, images, and video on your screen?*

The answer is number systems and data representation — the mathematical foundation underneath every programming language, file format, and piece of hardware you'll ever work with. You'll learn how computers count in binary, why hexadecimal shows up constantly in web development (hex color codes, for one), how memory is actually measured, and how something as abstract as a letter or an image ultimately reduces to a sequence of 1s and 0s.

**Difficulty:** ⭐ Beginner
**Estimated Time:** 8–10 hours (lessons + exercises)
**Prerequisites:** Module 01 — Computer Fundamentals
