# Interview Questions — Number Systems & Data Representation

## Beginner
- What is a number system, and what does "base" or "radix" mean?
- Why do computers use binary instead of decimal internally?
- What's the difference between a bit and a byte?
- Convert the decimal number 10 to binary and hexadecimal.

## Intermediate
- Explain how a hex color code like `#FFAA00` maps to RGB values.
- Why is 1 KB equal to 1024 bytes instead of 1000 bytes, and where do you still see the 1000-based version used instead?
- What's the difference between ASCII and Unicode, and why was Unicode necessary?
- How would you convert a binary number directly to hexadecimal without going through decimal first?

## Advanced
- Explain how UTF-8's variable-width encoding works, and why it was designed that way instead of using a fixed number of bytes per character like UTF-32.
- What is two's complement, and why do computers use it to represent negative numbers instead of just flipping a sign bit?
- Describe, at a high level, how an image file (e.g., PNG or JPEG) translates raw binary data into the picture you see on screen.
- What is endianness, and why can it cause bugs when systems exchange binary data over a network?
