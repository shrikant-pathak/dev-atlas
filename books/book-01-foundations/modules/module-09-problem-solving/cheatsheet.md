# 📄 Cheat Sheet — Problem Solving

## The Three Logic Building Blocks

| Block | Meaning |
|---|---|
| Sequence | Steps executed in order |
| Selection | Branching based on a condition (if/else) |
| Iteration | Repeating steps (loops) |

## Characteristics of a Good Algorithm

- Finite (must terminate)
- Precise / unambiguous
- Correct (works for all valid inputs)
- Efficient (reasonable time/resource use)

## Standard Flowchart Symbols

| Shape | Meaning |
|---|---|
| Oval | Start / End |
| Rectangle | Process / action |
| Diamond | Decision point |
| Parallelogram | Input / output |
| Arrow | Flow direction |

## Common Pseudocode Keywords

START / END
INPUT / OUTPUT
SET ... TO ...
IF ... THEN ... ELSE ... END IF
FOR ... / WHILE ... END FOR/WHILE
FUNCTION ... END FUNCTION
RETURN

## Types of Bugs

| Type | Description |
|---|---|
| Syntax error | Violates language grammar; caught before running |
| Runtime error | Valid syntax, fails while executing |
| Logic error | Runs fine, produces wrong result |

## Systematic Debugging Steps

Reproduce the bug reliably
Read error messages carefully
Form a hypothesis
Isolate the problem
Fix and verify

## Debugging Techniques

- Print debugging (`console.log()`)
- Breakpoints (DevTools Sources panel)
- Rubber duck debugging
- Reading the stack trace
