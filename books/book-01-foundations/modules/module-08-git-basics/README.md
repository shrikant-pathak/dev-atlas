## 📌 Module Overview

You've used Git commands throughout this entire roadmap already. This module finally slows down to build real conceptual understanding — what a repository, commit, branch, and merge actually are underneath the commands — and introduces GitHub's collaboration layer, especially Pull Requests, the standard workflow used by virtually every professional development team.

**Difficulty:** ⭐ Beginner
**Estimated Time:** 7–9 hours (lessons + exercises)
**Prerequisites:** Module 07 — Command Line
