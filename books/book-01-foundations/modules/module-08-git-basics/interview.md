# Interview Questions — Git Basics

## Beginner
- What is Git, and what problem does it solve?
- What's the difference between Git and GitHub?
- What is a commit?
- What is a branch?

## Intermediate
- What's the difference between `git add` and `git commit`?
- Explain the difference between a local and a remote repository.
- What is a merge conflict, and why does it happen?
- What's the difference between `git clone` and `git init`?

## Advanced
- Explain the difference between a fast-forward merge and a three-way merge.
- Walk through the full lifecycle of a Pull Request, from branch creation to merge.
- Why does Git use a staging area instead of committing all changes directly?
- What would you do if you accidentally committed directly to `main` instead of a feature branch?
