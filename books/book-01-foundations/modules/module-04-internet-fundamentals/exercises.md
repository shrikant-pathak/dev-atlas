# Exercise Set — Internet Fundamentals

## Easy
- [ ] Explain, in one sentence, the difference between the Internet and the World Wide Web.
- [ ] What is the default port for HTTP? For HTTPS?
- [ ] Name three common HTTP methods and what each is used for.
- [ ] What does DNS stand for, and what problem does it solve?

---

## Medium
- [ ] List, in order, the steps of a DNS lookup from browser cache to final response.
- [ ] Explain the difference between a public and a private IP address, and give an example of each.
- [ ] What is the difference between a 404 and a 500 status code? Which one indicates a client-side problem vs. a server-side problem?
- [ ] Explain what happens during a TLS handshake, in your own words.

---

## Hard
- [ ] Walk through, in full technical detail, everything that happens between typing a URL and seeing a rendered page — referencing DNS, IP, TCP/TLS, HTTP, and ports.
- [ ] A website loads over HTTP instead of HTTPS. List at least 3 concrete risks or downsides of this.
- [ ] Explain why a single server can run a web server (port 80/443), an SSH service (port 22), and a database (port 5432) all at the same time without conflicts.

---

## Bonus
- [ ] Research and explain what a CDN (Content Delivery Network) is and how it relates to DNS and the client-server model.
