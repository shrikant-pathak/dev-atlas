# Module 04: Internet Fundamentals

> **Book:** Book 01 — Foundations
> **Module:** 04 of Book 01

---

## 📌 Module Overview

Your code doesn't run in isolation — it runs on a network reachable by anyone in the world. This module covers how that global network actually works: what the Internet really is, how devices are addressed and found, and the protocols (HTTP, HTTPS) that let browsers and servers talk to each other. By the end, you'll be able to explain, in full technical detail, everything that happens between typing a URL and a page appearing on your screen — one of the most common questions asked in developer interviews.

**Difficulty:** ⭐ Beginner
**Estimated Time:** 8–10 hours (lessons + exercises)
**Prerequisites:** Module 01 — Computer Fundamentals, Module 03 — Operating Systems
