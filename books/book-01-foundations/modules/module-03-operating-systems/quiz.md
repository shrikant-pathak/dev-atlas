## Coding Questions
1. Write the macOS/Linux command to list all running processes.
2. Write the command to terminate a process with PID `4521` on macOS/Linux.

<details><summary>Answers</summary>

**Multiple Choice:** 1-b, 2-b, 3-c, 4-b

**True/False:** 1-True, 2-False (relative paths start from the current directory, not the root), 3-True

**Coding Question 1:** `ps aux`

**Coding Question 2:** `kill 4521`
