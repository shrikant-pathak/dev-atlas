## 📌 Module Overview

You've learned what a computer is made of and how it represents data — now it's time to learn about the software layer that ties it all together and makes it usable: the operating system. This module covers what an OS actually does, how the three major operating systems (Windows, macOS, Linux) compare, and core concepts — file systems, processes, threads, and user interfaces — that will keep coming up throughout your development career, especially once you start deploying code to real servers.

**Difficulty:** ⭐ Beginner
**Estimated Time:** 8–10 hours (lessons + exercises)
**Prerequisites:** Module 01 — Computer Fundamentals, Module 02 — Number Systems & Data Representation
