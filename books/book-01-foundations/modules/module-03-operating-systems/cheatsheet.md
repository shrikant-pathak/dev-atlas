# 📄 Cheat Sheet — Operating Systems

## OS Comparison

| | Windows | macOS | Linux |
|---|---|---|---|
| File System | NTFS | APFS | ext4 (most distros) |
| Default Shell | PowerShell | zsh | bash / zsh |
| Package Manager | winget | Homebrew | apt / dnf / yum |
| Dominant Use Case | Desktop, gaming, business | Desktop, creative/dev work | Servers, cloud, Android |
| Unix-based? | No (WSL adds this) | Yes (Darwin) | Yes |

## File Path Basics

| Concept | macOS/Linux Example | Windows Example |
|---|---|---|
| Absolute path | `/Users/name/project` | `C:\Users\Name\project` |
| Relative path (up one) | `../` | `..\` |
| Current directory | `./` | `.\` |
