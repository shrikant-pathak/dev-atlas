# Exercise Set — Operating Systems

## Easy
- [ ] List the three major operating systems and one defining trait of each.
- [ ] What is the difference between an absolute and a relative file path? Give one example of each.
- [ ] Open your system's process monitor (Task Manager / Activity Monitor) and name 3 running processes.
- [ ] What command lists running processes on macOS/Linux? On Windows?

---

## Medium
- [ ] Explain, in your own words, why Linux dominates servers even though Windows and macOS dominate desktops.
- [ ] Given the permission string `-rwxrw-r--`, describe exactly what the owner, group, and others can do.
- [ ] Explain the difference between a process and a thread, using an analogy of your own (not the "company and employees" one from the lesson).
- [ ] What is a race condition, and why is it a risk specific to multithreading rather than multiprocessing?

---

## Hard
- [ ] A Node.js server won't stop even after closing its terminal window. Walk through, step by step, how you'd find and terminate its process using the command line.
- [ ] Explain why JavaScript being "single-threaded" doesn't mean it can't handle multiple things happening concurrently. What mechanism allows this?
- [ ] Compare NTFS, APFS, and ext4 — name one meaningful difference between them beyond "they're used by different operating systems."

---

## Bonus
- [ ] Research and explain, in a few sentences, what a "zombie process" is and why it can occur.
