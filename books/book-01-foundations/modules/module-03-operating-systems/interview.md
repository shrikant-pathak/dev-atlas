# Interview Questions — Operating Systems

## Beginner
- What is an operating system, and what are its core responsibilities?
- What's the difference between a GUI and a CLI?
- Name the three major operating systems and one key difference between them.
- What is a file path, and what's the difference between absolute and relative paths?

## Intermediate
- Explain what a process is and how an OS runs multiple processes with a limited number of CPU cores.
- What's the difference between a process and a thread?
- Why do most web developers deploy their applications to Linux servers rather than Windows or macOS servers?
- What are file permissions, and how would you interpret the string `rwxr-xr-x`?

## Advanced
- Explain the process lifecycle and what triggers a process to move between states.
- What is a race condition, and how might you prevent one in a multithreaded program?
- Explain why JavaScript's single-threaded nature doesn't prevent it from handling asynchronous operations like network requests.
- Compare the tradeoffs between multiprocessing and multithreading for handling concurrent work.
