# Module 07: Command Line

> **Book:** Book 01 — Foundations
> **Module:** 07 of Book 01

---

## 📌 Module Overview

You got a first taste of the command line back in Module 01. This module builds real fluency: confidently navigating, creating, searching, and managing files and permissions entirely from the terminal, and using npm to manage project dependencies — skills you'll use every single day as a developer, especially once you start working with real projects and remote servers.

**Difficulty:** ⭐ Beginner
**Estimated Time:** 6–8 hours (lessons + exercises)
**Prerequisites:** Module 06 — Developer Environment
