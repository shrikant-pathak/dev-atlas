# Interview Questions — Command Line

## Beginner
- What command shows your current directory?
- What's the difference between `cp` and `mv`?
- What is `grep` used for?
- What is npm, and what problem does it solve?

## Intermediate
- What's the difference between `rmdir` and `rm -r`?
- Explain what the permission string `rwxr-xr-x` means, in both symbolic and numeric form.
- What's the difference between `dependencies` and `devDependencies` in `package.json`?
- What does the `-p` flag do when used with `mkdir`?

## Advanced
- Why is `rm -rf` considered one of the most dangerous commands, and what precautions would you take before running it?
- Explain how the pipe (`|`) operator works, with an example combining `find` and `grep`.
- What's the difference between installing an npm package globally versus locally, and when would you choose each?
- Walk through how you'd troubleshoot a "permission denied" error when trying to run a shell script.
