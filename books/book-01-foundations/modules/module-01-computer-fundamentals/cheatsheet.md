# Computer Basics

## What is a Computer?

A computer is an **electronic programmable device** that:

- Accepts **Input**
- Processes **Data**
- Stores **Information**
- Produces **Output**

```
Input → Processing → Storage → Output
```

# Fetch–Decode–Execute Cycle

```
RAM
 ↓
Fetch
 ↓
Decode
 ↓
Execute
 ↓
Store Result
 ↓
Next Instruction
```

This process repeats billions of times every second.

# Important Definitions

**CPU**
Brain of the computer.

**RAM**
Temporary working memory.

**ROM**
Permanent firmware memory.

**Motherboard**
Main circuit board.

**SSD**
Solid State Drive.

**HDD**
Hard Disk Drive.

**BIOS**
Basic Input/Output System.

**UEFI**
Modern firmware replacing BIOS.

**Kernel**
Core of the operating system.

**Bit**
Smallest unit of data.

**Byte**
8 bits.

| Correct Difference |
|--------------------|
| Hardware ≠ Software |
