# Module 01 Exercises
## Computer Fundamentals

> **Book:** Book 01 – Foundations
>
> **Module:** 01 – Computer Fundamentals
>
> **Difficulty:** Beginner

# Introduction

These exercises are designed to reinforce the concepts covered in **Module 01: Computer Fundamentals**. Complete them after studying all lessons. Some exercises require written answers, while others involve observing, identifying, researching, or performing simple practical tasks.

---

# Exercise 1 – Basic Concepts

Answer the following questions.

1. Define a computer in your own words.
2. Explain the difference between data and information with an example.
3. List the four basic functions of a computer.
4. Explain any five characteristics of a computer.
5. Why is a computer considered programmable?

---

# Exercise 2 – Types of Computers

Answer the following.

1. Differentiate between a desktop and a laptop.
2. Explain the purpose of a server.
3. Where are embedded systems commonly used?
4. Why are supercomputers important?
5. Give two real-world examples of workstations.

# Exercise 4 – Hardware Observation Activity

- Operating System
- Power Button
- Bootloader
- BIOS/UEFI
- Desktop
- POST

After arranging them, explain the purpose of each step in one or two sentences.

After completing these exercises, learners should be able to:

- Explain fundamental computer concepts clearly.
- Identify major hardware and software components.
- Apply theoretical knowledge to practical situations.
- Analyze basic computer operations.
- Communicate technical ideas using diagrams, tables, and examples.
- Build a strong foundation for the next module.
