# Lesson 01 – What Is a Computer?

A **computer** is an electronic device that accepts data as input, processes it according to instructions, stores it when necessary, and produces meaningful information as output.

Every computer, regardless of its size or purpose, follows the same basic **Input → Processing → Storage → Output** model.

### Key Concepts

- A computer is an electronic programmable machine.
- Data is the raw input; information is the processed output.
- Computers operate using instructions called programs.
- Every computer performs four basic functions:
  - Input
  - Processing
  - Storage
  - Output
- Computers are fast, accurate, reliable, and capable of handling large volumes of data.

### Remember

> A computer is not intelligent by itself—it only executes the instructions provided to it.

---

# Lesson 02 – History and Evolution of Computers

Computers have evolved from simple mechanical calculating devices into powerful digital systems capable of billions of calculations per second.

The development of computers is commonly divided into five generations based on the underlying technology used.

### Key Concepts

- Early calculating devices laid the foundation for modern computers.
- Mechanical computers evolved into electronic computers.
- Vacuum tubes, transistors, integrated circuits, and microprocessors each marked a new generation.
- Modern computers are faster, smaller, more energy-efficient, and more reliable than earlier systems.
- Artificial intelligence, cloud computing, and quantum computing represent emerging directions in computing.

### Remember

> Understanding the history of computing explains why modern computers are designed the way they are.

# Lesson 03 – Types of Computers

Computers come in many forms, each designed for different tasks, users, and performance requirements.

### Key Concepts

- Supercomputers solve highly complex scientific problems.
- Mainframes support large organizations and high-volume transactions.
- Servers provide services and resources to client computers.
- Workstations are designed for professional engineering, design, and scientific applications.
- Personal computers include desktops and laptops.
- Mobile devices such as smartphones and tablets are specialized computers.
- Embedded systems are computers built into everyday devices.

### Remember

> The primary difference between computer types lies in their purpose, performance, capacity, and scale.

---

# Lesson 04 – Computer Hardware Fundamentals

Hardware refers to the physical components of a computer system.

Every hardware component has a specific responsibility and works together with the others.

### Key Concepts

- Hardware includes all tangible parts of a computer.
- Major components include:
  - CPU
  - Motherboard
  - RAM
  - SSD/HDD
  - Power Supply
  - GPU
  - Input Devices
  - Output Devices
- Internal components communicate through the motherboard.
- Hardware and software depend on each other.

### Remember

> Hardware provides the physical infrastructure that allows software to operate.

---

# Lesson 05 – Computer Software Fundamentals

Software consists of programs and instructions that tell hardware what to do.

Without software, hardware cannot perform useful tasks.

### Key Concepts

- Software is classified into:
  - System Software
  - Application Software
  - Programming Software
- The operating system is the most important system software.
- Applications help users perform specific tasks.
- Programming tools are used to create software.

### Remember

> Hardware performs the work, but software provides the instructions.

---

# Lesson 06 – Operating Systems Basics

An operating system (OS) manages computer hardware and provides a platform for applications.

It acts as an intermediary between users, software, and hardware.

### Key Concepts

- The OS manages:
  - Memory
  - CPU scheduling
  - Files
  - Devices
  - Security
  - User interfaces
- Popular operating systems include:
  - Windows
  - Linux
  - macOS
  - Android
  - iOS
- The kernel is the core of the operating system.

### Remember

> Every application depends on the operating system to access hardware resources.

# Lesson 07 – How Computers Work Internally

Computers perform every task by coordinating hardware components through a sequence of well-defined operations.

### Key Concepts

- Pressing the power button starts the boot process.
- BIOS or UEFI initializes hardware.
- POST checks that essential hardware is functioning.
- The bootloader loads the operating system.
- Computers use binary (0s and 1s) to represent all digital data.
- The CPU contains the Control Unit (CU), Arithmetic Logic Unit (ALU), registers, and cache.
- RAM temporarily stores active programs and data.
- The motherboard connects all hardware components.
- Data travels through the Data Bus, Address Bus, and Control Bus.
- Every instruction is executed using the Fetch–Decode–Execute Cycle.

### Remember

> Every program, no matter how complex, is ultimately executed as a sequence of simple machine instructions processed by the CPU.

# Module 01 – Overall Takeaways

After completing this module, you should understand that:

- A computer is a programmable electronic system.
- Hardware and software work together to perform tasks.
- The operating system manages hardware resources and provides services to applications.
- Data is represented internally using binary numbers.
- The CPU executes instructions while RAM stores active data.
- Storage retains data permanently.
- The motherboard and system buses enable communication between components.
- Every action performed by a computer follows the Input → Processing → Storage → Output model.

These concepts form the foundation for studying programming, networking, databases, operating systems, cybersecurity, and software development in the modules ahead.
