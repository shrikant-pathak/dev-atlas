# Module 07: Errors, Debugging & Browser Storage

## Overview
This module covers how to handle failures gracefully, diagnose bugs efficiently using browser tools, and persist data client-side — the practical skills that separate hobby scripts from production-ready applications.

## Lessons
1. [Try/Catch and Custom Errors](lesson-01-try-catch-and-custom-errors.md)
2. [Debugging with DevTools](lesson-02-debugging-with-devtools.md)
3. [Local and Session Storage](lesson-03-local-and-session-storage.md)
4. [Cookies](lesson-04-cookies.md)
5. [Timers: setTimeout/setInterval](lesson-05-timers-settimeout-setinterval.md)
6. [Window API Basics](lesson-06-window-api-basics.md)

## Prerequisites
- Module 01: JS Fundamentals
- Module 02: Functions, Scope & Objects (closures, `this`)
- Module 04: DOM, Events & Navigation
- Module 05: Asynchronous JavaScript & APIs
- Module 06: ES6+ Modern Features (classes, optional chaining)

## Learning Outcomes
By the end of this module, you will be able to:
- Handle synchronous and asynchronous errors robustly, including custom error types
- Use browser DevTools effectively to diagnose bugs beyond `console.log`
- Persist data client-side with `localStorage`, `sessionStorage`, and cookies, choosing the right one for the job
- Schedule and manage delayed/repeating work with timers, including debounce and throttle patterns
- Use core `window` APIs for navigation, viewport, and connectivity awareness
