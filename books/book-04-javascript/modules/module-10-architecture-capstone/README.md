# Module 10: JS Architecture & Capstone Project

## Overview

This is the final module of Book 04 — JavaScript. It has two parts, deliberately different from every module before it: Lesson 1 teaches how to structure a real, multi-file vanilla JavaScript application using separation of concerns, and Lesson 2 is a full capstone project that applies that structure — and nearly every concept from Modules 01 through 09 — to build one complete, working application from scratch.

There's no new syntax to memorize here. This module exists to prove, concretely, that everything learned across this book fits together into something real — and to show precisely what frameworks like React and Vue (which you already use) are automating on your behalf.

## Lessons

1. **Organizing Large Vanilla JS Apps** — separation of concerns, a layered file structure, and a hand-built state/Observer system
2. **Capstone Project** — a complete task tracker app: state, persistence, API integration, error handling, and UI, built using Lesson 1's architecture and referencing concepts from every prior module

## Prerequisites

This module is the capstone of the entire book and draws on all nine prior modules, most directly:
- **Module 04** (DOM, Events & Navigation) — all rendering and event handling
- **Module 05** (Asynchronous JavaScript & APIs) — the capstone's API integration
- **Module 06** (ES6+ Modern Features) — `import`/`export` throughout every file
- **Module 07** (Errors, Debugging & Browser Storage) — custom error classes and `localStorage` persistence
- **Module 09** (Patterns, Style & Tooling) — the Observer pattern powering the state layer

## Book 04 Complete

Finishing this module completes **Book 04 — JavaScript** in full: 10 modules, from absolute fundamentals through async programming, modern syntax, legacy tech, tooling, and finally architecture and a real capstone project.
