# Module 03 — Strings, Numbers, Dates & Collections

## Overview
This module covers JavaScript's built-in data types in depth — strings, numbers, dates — and the collection types used to organize data: arrays, `Set`, and `Map`. It closes with the iterable protocol and generators, which explain how `for...of` works uniformly across all of them.

## Prerequisites
- Module 01 — JavaScript Fundamentals (complete)
- Module 02 — Functions, Scope & Objects (complete)

## Lessons
1. **String Methods and Templates** — template literals, searching/extracting/transforming text, string immutability
2. **Number and Math Methods** — parsing, formatting, validity checks, the `Math` object
3. **Date Object and Temporal** — creating/reading/formatting dates, `Date`'s limitations, the new `Temporal` API
4. **Arrays and Methods** — mutating vs. non-mutating methods, `map`/`filter`/`reduce`, searching and sorting
5. **Destructuring, Spread, Rest** — unpacking arrays/objects, copying/combining collections, variadic function arguments
6. **Sets and Maps** — unique value collections, flexible key-value pairs, when to choose each over a plain object
7. **Iterators and Generators** — the iterable protocol, `for...of`, `function*`/`yield`, custom iterables

## What You'll Be Able to Do After This Module
- Confidently manipulate strings, numbers, and dates using built-in methods
- Transform and summarize array data using `map`, `filter`, and `reduce`
- Choose the right collection type (`Array`, `Set`, `Map`, plain object) for a given situation
- Write and understand generator functions, and explain how `for...of` works under the hood
