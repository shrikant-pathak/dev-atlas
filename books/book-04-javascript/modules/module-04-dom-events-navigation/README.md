# Module 04 — DOM, Events & Navigation

## Overview
This module connects everything learned so far to a real, live web page. It covers selecting and traversing the DOM, handling user events (including delegation), working with forms and validation, and how the browser loads and executes scripts relative to the page.

## Prerequisites
- Module 01 — JavaScript Fundamentals (complete)
- Module 02 — Functions, Scope & Objects (complete)
- Module 03 — Strings, Numbers, Dates & Collections (complete)

## Lessons
1. **Selecting DOM Elements** — the DOM tree, `getElementById`/`querySelector`/`querySelectorAll`, live vs. static collections
2. **DOM Traversal** — parent/child/sibling navigation, `closest()`, `contains()`
3. **Event Handling and Delegation** — `addEventListener`, the event object, bubbling, event delegation
4. **Forms and Validation** — reading input values, handling submission, built-in and custom validation
5. **Script Loading — defer & async** — parser-blocking behavior, `defer` vs `async`, `DOMContentLoaded` vs `load`

## What You'll Be Able to Do After This Module
- Select and navigate any part of a page's DOM confidently
- Wire up interactive behavior with events, including efficient delegation patterns
- Build and validate real HTML forms with JavaScript
- Correctly reason about script loading order and DOM readiness
