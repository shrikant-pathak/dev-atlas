# Module 05 — Asynchronous JavaScript & APIs

## Overview
This module covers how JavaScript handles operations that take time — callbacks, Promises, and `async`/`await` — and applies all of it to the single most common real-world use case: fetching and sending data to a server via the Fetch API and JSON.

## Prerequisites
- Module 01 — JavaScript Fundamentals (complete)
- Module 02 — Functions, Scope & Objects (complete)
- Module 03 — Strings, Numbers, Dates & Collections (complete)
- Module 04 — DOM, Events & Navigation (complete)

## Lessons
1. **Callbacks** — synchronous vs. asynchronous callbacks, error-first convention, callback hell
2. **Promises** — states, `.then`/`.catch`/`.finally`, chaining, `Promise.all`/`allSettled`/`race`
3. **async/await** — syntax over Promises, `try`/`catch` error handling, running operations in parallel
4. **Fetch API** — making requests, the Response object, the "fetch doesn't reject on HTTP errors" gotcha, sending data
5. **Working with JSON and REST** — `JSON.stringify`/`parse`, REST conventions, building full CRUD operations

## What You'll Be Able to Do After This Module
- Reason confidently about asynchronous code in any of its three common forms
- Fetch data from and send data to a real API, handling both network and HTTP-level errors correctly
- Convert data between JavaScript objects and JSON
- Understand and apply REST conventions when designing or consuming an API
