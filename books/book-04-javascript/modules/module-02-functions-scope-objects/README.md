# Module 02 — Functions, Scope & Objects

## Overview
This module covers two of JavaScript's most foundational concepts: functions (how to package and reuse behavior) and objects (how to structure and share data and behavior together). Everything from here on — DOM manipulation, async code, and eventually React/Vue components — is built out of functions and objects.

## Prerequisites
- Module 01 — JavaScript Fundamentals (complete)

## Lessons
1. **Function Declarations, Expressions, Arrow Functions** — the three ways to write a function, parameters, defaults, return values
2. **Scope and Hoisting** — global/function/block scope, lexical scoping, hoisting, the Temporal Dead Zone
3. **Closures** — functions that remember their outer scope, private state, function factories
4. **Higher-Order Functions** — functions as arguments and return values, callbacks
5. **The `this` Keyword** — how `this` is determined by call-site, arrow functions vs regular functions, `call`/`apply`/`bind`
6. **IIFE** — immediately invoked function expressions, the module pattern, why they're less common today
7. **Object Literals and Methods** — creating objects, dot/bracket notation, methods, shorthand syntax
8. **Prototypes and Inheritance** — the prototype chain, constructor functions, building inheritance
9. **Object.create, Getters and Setters** — prototypal object creation, computed and validated properties

## What You'll Be Able to Do After This Module
- Write functions in all three JavaScript syntaxes and choose the right one for the situation
- Reason correctly about scope, hoisting, and closures — including common interview questions on all three
- Confidently predict what `this` refers to in any given function call
- Build and structure objects, including shared behavior via prototypes and computed properties via getters/setters
