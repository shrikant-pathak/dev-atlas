# Module 01 — JavaScript Fundamentals

## Overview
This module introduces JavaScript as the third pillar of the web (alongside HTML and CSS covered in Books 02 and 03), and builds the core syntax and logic every later module — and every framework in this learning path (React, React Native, Vue) — depends on.

## Prerequisites
- Book 01 — Foundations (complete)
- Book 02 — HTML (complete)
- Book 03 — CSS (complete)

## Lessons
1. **Intro to JavaScript** — what JS is, how to add it to a page, the browser console
2. **Syntax and Comments** — statements, semicolons/ASI, whitespace, single- and multi-line comments
3. **Variables — let, const, var** — declaration, block vs. function scope, reassignment vs. mutation
4. **Data Types and Type Coercion** — primitive types, `typeof`, implicit/explicit coercion, `==` vs `===`, truthy/falsy
5. **Operators** — arithmetic, assignment, comparison, logical operators, the ternary operator
6. **Control Flow — Conditionals** — `if`/`else if`/`else`, `switch`
7. **Loops** — `for`, `while`, `do...while`, `break`/`continue`

## What You'll Be Able to Do After This Module
- Add JavaScript to any HTML page and run it
- Write clean, correctly structured JavaScript following standard conventions
- Declare and use variables correctly, understanding scope and reassignment vs. mutation
- Reason confidently about types and coercion, including common `==` pitfalls
- Write conditional logic and loops to control program flow
