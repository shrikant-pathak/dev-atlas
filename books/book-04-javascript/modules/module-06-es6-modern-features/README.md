# Module 06: ES6+ Modern Features

## Overview
This module covers the modern JavaScript syntax and language features introduced from ES6 (2015) onward — the features that define how contemporary JavaScript, React, Vue, and React Native code is actually written today.

## Lessons
1. [ES6 Modules (import/export)](lesson-01-es6-modules-import-export.md)
2. [Classes and Inheritance](lesson-02-classes-and-inheritance.md)
3. [Optional Chaining & Nullish Coalescing](lesson-03-optional-chaining-nullish-coalescing.md)
4. [RegExp Basics](lesson-04-regexp-basics.md)
5. [ES Version History](lesson-05-es-version-history.md)

## Prerequisites
- Module 01: JS Fundamentals
- Module 02: Functions, Scope & Objects
- Module 03: Strings, Numbers, Dates & Collections
- Module 05: Asynchronous JavaScript & APIs (for dynamic imports)

## Learning Outcomes
By the end of this module, you will be able to:
- Structure code across files using ES Modules
- Build class hierarchies with proper inheritance and encapsulation
- Write concise, safe code for accessing nested/optional data
- Use regular expressions for validation and text processing
- Place any given JavaScript feature in its historical ES version context
