# Module 04: Colors, Backgrounds & Spacing

## Overview
This module covers Bootstrap's visual foundation utilities: the theme color system, text/background color utilities and their subtle/opacity variants, borders and rounding, the spacing scale, and sizing utilities. Together these form the utility vocabulary you'll combine with every component in Modules 05–12.

## Lessons
1. **Theme Colors and the Color System** — the eight theme colors, CSS variables, applying colors via components and utilities
2. **Text and Background Colors** — `.text-*`, `.bg-*`, subtle variants, opacity utilities
3. **Borders** — adding/removing borders, direction, color, width, rounding
4. **The Spacing Scale** — the `{property}{sides}-{size}` syntax, margin vs. padding, responsive spacing
5. **Sizing Utilities** — percentage width/height, viewport sizing, max-width/height for media

## Prerequisites
- Module 01 (Bootstrap Fundamentals) — grid basics, utility class philosophy
- Module 02 (Layout and Grid System) — flex utilities, breakpoints, responsive infixes
- Module 03 (Typography and Content) — text utilities, first exposure to `.text-muted`

## What's Next
Module 05 (Forms) builds directly on this module's color and spacing system for form validation states (`.is-valid`/`.is-invalid`, which use the `success`/`danger` theme colors) and form control spacing.
