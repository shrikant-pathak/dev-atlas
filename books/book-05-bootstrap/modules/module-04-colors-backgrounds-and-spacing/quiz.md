# Module 04 Quiz

1. Which of these is NOT one of Bootstrap's eight default theme colors?
   a) primary  b) accent  c) warning  d) dark
   **Answer: b) accent**

2. What CSS variable exposes the "primary" theme color?
   a) `--bootstrap-primary`  b) `--bs-primary`  c) `--primary-color`  d) `--theme-primary`
   **Answer: b) `--bs-primary`**

3. Which class pair is the correct "subtle" pattern for a success-themed tag?
   a) `bg-success` + `text-success`
   b) `bg-success-subtle` + `text-success-emphasis`
   c) `bg-success-light` + `text-success-dark`
   d) `bg-subtle-success` + `text-emphasis-success`
   **Answer: b) `bg-success-subtle` + `text-success-emphasis`**

4. What does `border-bottom-0` do when combined with `.border`?
   a) Adds a border only on the bottom
   b) Removes the border on the bottom while keeping the others
   c) Sets the border-bottom width to 0px on all sides
   d) Has no effect
   **Answer: b) Removes the border on the bottom while keeping the others**

5. What is required for `.rounded-circle` to render a true circle?
   a) The element must have a `border`
   b) The element must be inside a flex container
   c) The element must have equal width and height
   d) Nothing — it always renders a circle
   **Answer: c) The element must have equal width and height**

6. Decode `my-3`:
   a) margin-left and margin-right, size 3
   b) margin-top and margin-bottom, size 3
   c) margin on all sides, size 3
   d) Not a valid Bootstrap class
   **Answer: b) margin-top and margin-bottom, size 3**

7. In the spacing scale, what does size `0` represent?
   a) The default/unset spacing value
   b) `0` — no spacing at all
   c) The smallest non-zero spacing step
   d) `auto` spacing
   **Answer: b) `0` — no spacing at all**

8. Which utility guarantees a section is at least full-screen height but can still grow taller?
   a) `.vh-100`
   b) `.h-100`
   c) `.min-vh-100`
   d) `.max-vh-100`
   **Answer: c) `.min-vh-100`**

9. What does `.mw-100` do to an image smaller than its container?
   a) Stretches it to fill 100% of the container
   b) Has no effect, since it only constrains sizes larger than 100%
   c) Shrinks it to 50% of its natural size
   d) Centers it within the container
   **Answer: b) Has no effect, since it only constrains sizes larger than 100%**

10. Which spacing utility pattern is used to push a single item to the far end of a flex row?
    a) `.p-auto`
    b) `.ms-auto` (or `.me-auto` depending on direction)
    c) `.w-auto`
    d) `.border-auto`
    **Answer: b) `.ms-auto` (or `.me-auto` depending on direction)**
