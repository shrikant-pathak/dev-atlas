# Module 04 Exercises

## Exercise 1 — Status Badges (Lesson 01)
Build a row of four badges using `bg-success`, `bg-danger`, `bg-warning text-dark`, and `bg-info text-dark`, each labeled with a status word of your choice.

## Exercise 2 — Subtle Tag List (Lesson 02)
Recreate the "subtle" tag pattern (`bg-{color}-subtle` + `text-{color}-emphasis` + `border-{color}-subtle`) for three different theme colors, applied to `<span>` pill tags.

## Exercise 3 — Bordered Avatar Card (Lesson 03)
Build a profile card with a circular avatar (`rounded-circle`), a `border-3 border-primary` on the avatar, and a `rounded-3` container border around the whole card.

## Exercise 4 — Responsive Padding Card (Lesson 04)
Build a card with padding that's `p-2` on mobile, `p-4` at `md`, and `p-5` at `lg`. Add a `mb-4` for spacing below the card. Verify at each breakpoint using your browser's responsive dev tools.

## Exercise 5 — Full-Screen Hero (Lesson 05)
Build a hero section using `min-vh-100`, `d-flex`, `align-items-center`, and `justify-content-center`, containing a heading and a button. Confirm it still displays correctly if you add enough extra text to overflow one screen height.

## Challenge — Combine All Five
Build a single pricing card that uses: a theme-colored header background (Lesson 01), a subtle badge for "Popular" (Lesson 02), a `border-2 border-primary rounded-3` outline (Lesson 03), responsive internal padding (Lesson 04), and a `mw-100` constrained image or icon (Lesson 05).
