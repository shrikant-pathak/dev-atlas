# Module 02 Exercises — Layout & Grid System

## Exercise 1 — Container Comparison
Build one page with a `.container`, another section with `.container-fluid`, and a third with `.container-md`. Resize your browser and describe what happens to each at every breakpoint.

## Exercise 2 — Equal Columns
Build a row with four unsized `.col` elements. Add borders to each so you can see them split the row into four equal parts.

## Exercise 3 — Explicit Sizing
Build a row with three columns sized `col-3`, `col-5`, and `col-4`. Confirm they exactly fill one row (3+5+4=12).

## Exercise 4 — Responsive Product Grid
Build a product grid: 1 column on mobile, 2 columns at `sm`, 3 columns at `md`, 4 columns at `lg`, using a single responsive class combination per column.

## Exercise 5 — Offset Centering
Center a single `col-md-6` box horizontally using an offset class instead of text-alignment tricks.

## Exercise 6 — Reordering
Build a two-column row where, on mobile, Column A appears above Column B, but from `md` up, Column B visually appears first — without changing the HTML source order.

## Exercise 7 — Gutter Practice
Build a 6-item card grid that wraps across two rows. Apply tight horizontal gutters (`gx-1`) but generous vertical gutters (`gy-4`) between the wrapped rows.

## Exercise 8 — Stacked-to-Horizontal Form
Build a two-field form (Name, Email) where each label sits above its input on mobile, but beside it from `md` up.

## Exercise 9 — Blog Layout
Build a two-column blog layout: a wide main content column and a narrower sidebar, stacking on mobile and side-by-side from `lg` up.

## Exercise 10 — Notification Badge
Build a button with a small numbered badge positioned exactly on its top-right corner, using position and z-index utilities.
