# Module 02 Interview Questions — Layout & Grid System

1. What is the difference between `.container`, `.container-fluid`, and `.container-md`?
2. What are Bootstrap's default breakpoints and their pixel thresholds?
3. Explain why Bootstrap's breakpoints use min-width media queries rather than max-width, and what that means for how classes like `col-md-6` behave at larger breakpoints.
4. How many units does Bootstrap's grid divide a row into, and how do you size a column relative to that?
5. What happens when column sizes in a single row add up to more than 12?
6. How would you center a column horizontally using offset classes?
7. Explain the difference between reordering columns with `.order-*` versus physically reordering your HTML — and why the distinction matters for accessibility.
8. What two CSS mechanisms combine to produce Bootstrap's default column gutters?
9. What's the difference between `.gx-*` and `.gy-*`?
10. Describe the "stacked on mobile, side-by-side on desktop" pattern and give two real-world components where it commonly appears.
11. Why would a primary navigation bar typically NOT use the plain stacked-to-horizontal grid pattern?
12. What is Bootstrap's own z-index utility scale meant for, versus the much higher z-index values used internally by components like modals and dropdowns?
13. What CSS property must an element have before z-index has any visible effect on it?
14. What does `.translate-middle` do, and what's it commonly combined with?
15. Why should a `.row` typically be placed inside a container rather than directly in the page body?
