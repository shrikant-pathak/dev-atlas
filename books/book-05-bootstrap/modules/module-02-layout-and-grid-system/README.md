# Module 02 — Layout & Grid System

## Overview
This module covers Bootstrap's layout foundation: containers, breakpoints, the 12-column grid, column sizing, gutters, the ubiquitous "stack on mobile, horizontal on desktop" pattern, and z-index/positioning utilities. By the end, you'll be able to build any responsive multi-column layout using Bootstrap's grid system.

## Lessons
1. **Containers** — `.container`, `.container-fluid`, breakpoint-specific containers
2. **Breakpoints** — the default breakpoint scale, mobile-first min-width behavior
3. **The Grid System** — `.row`/`.col`, the 12-unit model, auto vs sized columns, nesting
4. **Columns & Column Sizing** — responsive sizing, offsetting, ordering, alignment
5. **Gutters** — how gutters work, `.g-*`/`.gx-*`/`.gy-*`, responsive gutters
6. **Stacked-to-Horizontal Patterns** — the core responsive layout pattern applied to real components
7. **Z-index & Layout Utilities** — Bootstrap's z-index scale, internal component z-index, position utilities

## Prerequisites
Module 01 — Bootstrap Fundamentals, and Book 03 — CSS (Flexbox, Box Model, Positioning, Responsive Design modules).

## What You Should Be Able to Do After This Module
- Choose the correct container type for a layout
- Build any responsive multi-column layout using rows and columns
- Control gutter spacing responsively
- Recognize and build the stacked-to-horizontal pattern in forms, media objects, and feature grids
- Layer content correctly using position and z-index utilities without conflicting with Bootstrap's own components
