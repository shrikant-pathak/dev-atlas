# Module 07: Core Components II

## Overview
This module continues from Module 06 into navigation-and-structure-oriented components: navbar, nav/tabs, breadcrumb, pagination, dropdowns, offcanvas, and list groups. It's the most accessibility-attribute-heavy module so far, and the first to lean heavily on Bootstrap's bundled JavaScript (collapse, tab, dropdown, offcanvas behaviors) ahead of Module 08's deeper dive into interactive components.

## Lessons
1. **Navbar** — responsive collapsible navigation, color schemes, forms in a navbar
2. **Nav and Tabs** — `.nav` styling variants, functional tab switching, vertical navs
3. **Breadcrumb** — hierarchical trail, current-page marking, custom separators
4. **Pagination** — page controls, disabled boundary states, sizing, alignment
5. **Dropdowns** — toggle menus, split buttons, directional variants, Popper positioning
6. **Offcanvas** — sliding drawer panels, positioning, backdrop/scroll control, responsive sidebars
7. **List Groups** — item states, contextual colors, actionable lists, horizontal/flush variants

## Prerequisites
- Module 02 (Layout and Grid System) — flex utilities used throughout (navbar, list group alignment)
- Module 04 (Colors, Backgrounds & Spacing) — theme colors, CSS variable customization (breadcrumb divider)
- Module 05 (Forms) — `.visually-hidden`, `.form-check` reused in dropdowns and offcanvas examples
- Module 06 (Core Components I) — `.btn`/`.btn-group` (dropdowns), `.btn-close`/`data-bs-dismiss` (offcanvas), badges (list groups)

## What's Next
Module 08 (Interactive Components) goes deeper into the JavaScript-driven behaviors previewed here (collapse, dropdown positioning) with modals, toasts, tooltips, popovers, and carousels.
