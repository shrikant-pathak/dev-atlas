# Module 07 Exercises

## Exercise 1 — Responsive Navbar (Lesson 01)
Build a dark navbar with brand, 3 nav links, and a search form, collapsing below `lg`.

## Exercise 2 — Functional Settings Tabs (Lesson 02)
Build 3 tabs (General, Notifications, Security) with working content switching and full ARIA wiring.

## Exercise 3 — Nested Breadcrumb (Lesson 03)
Build a 4-level breadcrumb trail with a custom `>` separator.

## Exercise 4 — Search Results Pagination (Lesson 04)
Build a centered pagination control with a disabled "Previous" on the first page.

## Exercise 5 — Account Dropdown (Lesson 05)
Build a user account dropdown with a header, 3 items, a divider, and one disabled item.

## Exercise 6 — Mobile Filter Drawer (Lesson 06)
Build a responsive offcanvas (`.offcanvas-lg`) containing 3 checkbox filters, hidden trigger button above `lg`.

## Exercise 7 — Actionable Notification List (Lesson 07)
Build a list group of 4 clickable notifications, each with a badge, one marked active.

## Challenge — Full App Shell
Combine all seven lessons: a navbar (Lesson 01) containing a dropdown (Lesson 05), a breadcrumb (Lesson 03) below it, a tabbed content area (Lesson 02) with a paginated list group inside one tab (Lessons 04 + 07), and a filter offcanvas (Lesson 06) triggered from the navbar.
