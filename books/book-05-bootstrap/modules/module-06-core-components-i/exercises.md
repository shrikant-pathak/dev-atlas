# Module 06 Exercises

## Exercise 1 — Button Variant Grid (Lesson 01)
Build a grid showing all eight theme colors in both solid and outline button form, plus one disabled and one active example.

## Exercise 2 — View Toggle (Lesson 02)
Build a segmented "Grid / List / Table" toggle using `.btn-group` + `.btn-check` radio inputs.

## Exercise 3 — Notification Bell (Lesson 03)
Build a button with a floating pill-shaped badge showing an unread count, using the position utility pattern.

## Exercise 4 — Dismissible Alert Stack (Lesson 04)
Build three stacked dismissible alerts (success, warning, danger), each with a heading and a linked call to action.

## Exercise 5 — Pricing Card Row (Lesson 05)
Build three pricing cards in an equal-height grid row (`.row-cols-md-3 .h-100`), each with a header, list group, and button.

## Exercise 6 — Dark Banner with Close (Lesson 06)
Build a dark-background announcement banner with a `.btn-close-white` dismiss button.

## Exercise 7 — Multi-Step Upload Progress (Lesson 07)
Build three progress bars: one static colored bar, one striped bar, and one striped + animated bar, each with correct ARIA attributes.

## Challenge — Dashboard Widget
Combine all seven lessons into one card: a header with a badge, an alert inside the card body for a warning message, a progress bar showing completion, and a button group for actions — all within a single `.card`.
