# Module 06 Quiz

1. In Bootstrap 5, how do you make a button span the full width of its container?
   a) `.btn-block`  b) `.btn-full`  c) `.w-100`  d) `.btn-100`
   **Answer: c) `.w-100`**

2. What's true about `.active` on a button?
   a) It disables the button  b) It's purely visual and doesn't disable the button  c) It removes the button from tab order  d) It changes the button's type attribute
   **Answer: b) It's purely visual and doesn't disable the button**

3. What does `.btn-check` do to a radio/checkbox input?
   a) Adds a checkmark icon  b) Visually hides it while keeping it functional  c) Disables it  d) Converts it to a button element
   **Answer: b) Visually hides it while keeping it functional**

4. What class provides a badge's actual color?
   a) `.badge-color`  b) `.bg-{color}`  c) `.text-{color}`  d) Badges have a fixed, unchangeable color
   **Answer: b) `.bg-{color}`**

5. What attribute is required on an alert for accessibility?
   a) `aria-live`  b) `role="alert"`  c) `data-alert`  d) `tabindex="0"`
   **Answer: b) `role="alert"`**

6. What does `.card-img-top` primarily handle?
   a) Adding a caption  b) Lazy loading  c) Cropping the image to match the card's rounded top corners  d) Setting a fixed aspect ratio
   **Answer: c) Cropping the image to match the card's rounded top corners**

7. Why is `.h-100` used in a row of cards?
   a) To limit card height to 100px  b) To make every card stretch to fill its equal-height grid column  c) To hide overflow content  d) It has no visual effect
   **Answer: b) To make every card stretch to fill its equal-height grid column**

8. Why is `aria-label="Close"` required on `.btn-close`?
   a) It's optional but recommended  b) The button has no visible text content, so screen readers need it to announce anything  c) It changes the button's color  d) It's required by HTML validators only
   **Answer: b) The button has no visible text content, so screen readers need it to announce anything**

9. Why is a progress bar's width set with inline `style` instead of a utility class?
   a) It's a legacy pattern Bootstrap hasn't updated  b) Progress values are arbitrary/continuous, so no fixed set of classes could cover them  c) Utility classes don't support percentages  d) It's actually possible and preferred to use a utility class instead
   **Answer: b) Progress values are arbitrary/continuous, so no fixed set of classes could cover them**

10. What three ARIA attributes must appear on the outer `.progress` element?
    a) `aria-current`, `aria-live`, `aria-busy`  b) `aria-valuenow`, `aria-valuemin`, `aria-valuemax`  c) `aria-label`, `aria-hidden`, `aria-role`  d) None are required
    **Answer: b) `aria-valuenow`, `aria-valuemin`, `aria-valuemax`**
