# Module 06: Core Components I

## Overview
This module introduces the first set of general-purpose UI components: buttons, button groups, badges, alerts, cards, close buttons, and progress bars. It's a natural bridge from Module 05's form-specific controls to broader page-building components, and heavily reuses the theme colors and utilities from Module 04.

## Lessons
1. **Buttons** — `.btn` color/outline/size variants, disabled vs. active state, buttons on different elements
2. **Button Groups** — `.btn-group`, vertical groups, checkbox/radio groups (`.btn-check`), toolbars
3. **Badges** — `.badge`, pill badges, badges in headings/buttons, badges vs. alerts
4. **Alerts** — `.alert` variants, headings/links inside alerts, dismissible alerts, `data-bs-dismiss`
5. **Cards** — card structure, images, headers/footers, list groups in cards, equal-height card grids
6. **Close Button** — `.btn-close`, dark-background variant, `data-bs-dismiss` beyond alerts
7. **Progress Bars** — `.progress`/`.progress-bar`, ARIA attributes, striped/animated, stacked bars

## Prerequisites
- Module 02 (Layout and Grid System) — grid used for card rows and toolbars
- Module 04 (Colors, Backgrounds & Spacing) — theme colors used throughout every component in this module
- Module 05 (Forms) — `.form-check` pattern reused in button groups; `.visually-hidden` reused in badges

## What's Next
Module 07 (Core Components II) continues with navigation-oriented components (navbar, navs, tabs, breadcrumbs, pagination) that build directly on the buttons and button groups from this module.
