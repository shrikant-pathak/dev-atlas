# Module 12 Exercises

## Exercise 1 — Icon Toolbar (Lesson 01)
Build a toolbar of 4 icon-only buttons (save, print, share, delete) with correct accessibility labeling for each.

## Exercise 2 — Themed Icon Set (Lesson 01)
Build a status list using icons colored via `.text-{color}` (webfont) matching each status's meaning (success, warning, danger).

## Exercise 3 — Event-Driven Modal (Lesson 02)
Build a modal that auto-focuses its first input on `shown.bs.modal` and resets its form on `hidden.bs.modal`.

## Exercise 4 — Coordinated Delete Flow (Lesson 02)
Build a confirm-modal-then-toast flow using the JS API (`getInstance`, `.hide()`, `new bootstrap.Toast().show()`).

## Exercise 5 — Capstone Landing Page
Build the full landing page from Lesson 03's mapping table: navbar with theme toggle, hero, 3-column feature cards, testimonial carousel, newsletter input group, footer with `.vr` dividers.

## Exercise 6 — Capstone Services Page
Build the services page: breadcrumb, accordion, pricing cards, and a validated "Book now" modal.

## Exercise 7 — Capstone Contact Page
Build the contact page: validated form, success toast on submit (via the JS API), ratio-embedded map, icon social links.

## Final Challenge — Full Capstone Site
Assemble all three pages into one working project with a shared custom Sass theme (Module 11), working dark mode (Module 10) persisted via localStorage across all three pages, and a full accessibility + responsive pass against Module 09, Lesson 09's seven patterns.
