# Module 12: Icons and Real-World Project

## Overview
This is the final module of Book 05 — it covers Bootstrap Icons (the official companion icon library) and integrating Bootstrap's JavaScript API/events with custom vanilla JS logic, then closes the entire book with a capstone lesson: a full real-world project specification mapping every page and section back to the specific module and lesson that covers it.

## Lessons
1. **Bootstrap Icons** — CDN/npm/SVG inclusion methods, webfont vs. SVG sizing/coloring, decorative vs. meaningful icon accessibility
2. **Integrating Bootstrap JS with Vanilla JS** — custom component events (`shown.bs.modal`, etc.), the JS API (`new bootstrap.Modal()`, `.getInstance()`), coordinating multiple components from one piece of application state
3. **Capstone Project** — a full 3-page small business site, mapped module-by-module, with a suggested build order

## Prerequisites
- Every prior module in Book 05 — this module is a deliberate synthesis, explicitly referencing components and utilities from Modules 02, 04–11 throughout its capstone mapping
