# Module 05 Quiz

1. Which class is applied directly to a text `<input>` for standard Bootstrap styling?
   a) `.form-input`  b) `.form-control`  c) `.input-control`  d) `.text-input`
   **Answer: b) `.form-control`**

2. What's the "medium"/default size class for a form control?
   a) `.form-control-md`  b) `.form-control-default`  c) There isn't one — unmodified `.form-control` is the default  d) `.form-control-normal`
   **Answer: c) There isn't one — unmodified `.form-control` is the default**

3. What attribute makes a group of radio buttons mutually exclusive?
   a) `group`  b) `name`  c) `id`  d) `form-check-group`
   **Answer: b) `name`**

4. What does `.form-switch` change about a checkbox's behavior?
   a) Nothing behaviorally — it's purely visual  b) Makes it submit a different value  c) Converts it into a button  d) Requires JavaScript to function
   **Answer: a) Nothing behaviorally — it's purely visual**

5. What native attribute controls the increment a range slider snaps to?
   a) `increment`  b) `snap`  c) `step`  d) `interval`
   **Answer: c) `step`**

6. In an `.input-group`, where should size classes like `.input-group-lg` be applied?
   a) On the input only  b) On the wrapping `.input-group` element  c) On the button only  d) On the `.input-group-text` only
   **Answer: b) On the wrapping `.input-group` element**

7. What markup order does `.form-floating` require?
   a) Label, then input  b) Input, then label  c) Order doesn't matter  d) Label wrapped inside the input
   **Answer: b) Input, then label**

8. What does `.g-3` do inside a form's `.row`?
   a) Sets grid column width to 3  b) Applies consistent gutter spacing between rows/columns  c) Sets a fixed height of 3rem  d) Nothing, it's not a valid class
   **Answer: b) Applies consistent gutter spacing between rows/columns**

9. What does `novalidate` on a `<form>` do?
   a) Disables all form submission  b) Disables the browser's native validation popups  c) Removes all `required` attributes  d) Prevents JavaScript from running on the form
   **Answer: b) Disables the browser's native validation popups**

10. What class, once added to a form, activates `.is-valid`/`.is-invalid` styling based on current field validity?
    a) `.form-validated`  b) `.validate-now`  c) `.was-validated`  d) `.is-checked`
    **Answer: c) `.was-validated`**
