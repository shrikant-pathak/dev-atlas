# Module 05 Exercises

## Exercise 1 — Contact Form Fields (Lesson 01)
Build a name, email, and message field group using `.form-control`, proper `.form-label` pairing, and `.form-text` helper text under the email field.

## Exercise 2 — Country/Language Selects (Lesson 02)
Build two selects: a single-select for country using `<optgroup>` to separate "Domestic"/"International", and a multi-select for preferred languages.

## Exercise 3 — Notification Settings (Lesson 03)
Build a settings panel with two `.form-switch` toggles and one inline radio group (3 options) for a "frequency" setting.

## Exercise 4 — Price Range Filter (Lesson 04)
Build two range sliders (min price, max price) with live value display using vanilla JS `addEventListener`.

## Exercise 5 — Search Bar and Price Field (Lesson 05)
Build a search input with an attached button using `.input-group`, and a price field with a `$` prefix and `.00` suffix.

## Exercise 6 — Floating Label Login (Lesson 06)
Rebuild a login form (email + password) entirely using `.form-floating` instead of standard labels.

## Exercise 7 — Multi-Column Address Form (Lesson 07)
Build a full address form: name (2 columns), street (1 full-width column), city/state/zip (3 columns) — all using the grid.

## Exercise 8 — Validated Signup Form (Lesson 08)
Build a signup form (name, email, password, terms checkbox) using the `.needs-validation` + `checkValidity()` pattern, with proper `.invalid-feedback` messages for each field.

## Challenge — Full Registration Form
Combine all 8 lessons into one form: floating labels for name/email, a grid-based address section, an input-group phone field, a switch for "email me updates," and full client-side validation on submit.
