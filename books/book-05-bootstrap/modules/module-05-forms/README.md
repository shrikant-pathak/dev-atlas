# Module 05: Forms

## Overview
This module covers every core Bootstrap form control and the patterns needed to lay them out and validate them: text/textarea controls, selects, checkboxes/radios/switches, range sliders, input groups, floating labels, grid-based form layouts, and client-side validation.

## Lessons
1. **Form Controls** — `.form-control`, sizes, labels, helper text, disabled/readonly
2. **Select Menus** — `.form-select`, multi-select, `<optgroup>`
3. **Checks and Radios** — `.form-check` pattern, switches, inline layout, reverse layout
4. **Range Inputs** — `.form-range`, min/max/step, live value display
5. **Input Groups** — `.input-group`, prepend/append text and buttons, sizing
6. **Floating Labels** — `.form-floating`, markup order requirements, supported control types
7. **Form Layout** — grid-based multi-column forms, horizontal label layouts, `.col-form-label`
8. **Form Validation** — `.is-valid`/`.is-invalid`, `.needs-validation` + Constraint Validation API

## Prerequisites
- Module 02 (Layout and Grid System) — grid, gutters, `.col-auto`, flex alignment
- Module 04 (Colors, Backgrounds & Spacing) — theme colors (used directly in validation states), spacing utilities used throughout every form example
- Book 04, Module 04 (DOM, Events & Navigation) — `addEventListener`, reading input `.value`, used in range input and validation lessons

## What's Next
Module 06 (Core Components I) moves from form-specific controls to general-purpose UI components — cards, buttons, alerts — many of which you'll combine directly with the forms built in this module.
