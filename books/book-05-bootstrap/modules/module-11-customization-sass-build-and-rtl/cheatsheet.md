# Module 11 Cheatsheet

## Setup
```bash
npm install bootstrap @popperjs/core
npm install -D sass
npx sass scss/custom.scss css/custom.css
npx sass --watch scss/custom.scss css/custom.css
```
Override variables BEFORE `@import "bootstrap"` (Sass `!default` resolution)

## Variables & Maps
```scss
$primary: #6f42c1;
$spacer: 1.25rem;          // reshapes entire spacing scale
$theme-colors: ( ...existing..., "brand": #ff6b35 );  // adds .btn-brand, .text-brand, etc.
$grid-breakpoints: ( ...existing..., xxxl: 1600px );  // adds .col-xxxl-*, .d-xxxl-*
```

## Selective Imports (always required first)
```scss
@import "functions"; @import "variables"; @import "maps";
@import "mixins";    @import "root";
// then only the components/utilities actually used
```

## Sass vs. CSS Custom Properties
| | Sass variable | CSS custom property (`--bs-*`) |
|---|---|---|
| Exists | Build time only | Runtime, in browser |
| Changed via | Recompile | DevTools / inline style / JS, live |
| Use for | Permanent brand identity | Dark mode, per-user runtime changes |
| Generated by | — | `_root.scss` (from Sass values) |

## Bundle Size
- Full build: ~200+ KB uncompressed
- Trim components: import only needed partials (Lesson 03)
- Trim utilities: `$utilities: ("border-radius": null, ...);`
- Tradeoff: selective = smaller but must remember every import; full = forgiving, simplest default

## RTL
```scss
$rtl: true;
@import "../node_modules/bootstrap/scss/bootstrap";
```
```html
<html dir="rtl" lang="ar">
```
Flips automatically: logical-property classes (`.ms-*`, `.border-start`, `.offcanvas-start`)
Does NOT flip automatically: icon direction, hardcoded physical properties in custom CSS, non-CSS-driven markup order
