# Module 10 Exercises

## Exercise 1 — Split-Theme Page (Lesson 01)
Build a page with a dark-themed header section and a light-themed body section, both using standard Bootstrap components.

## Exercise 2 — System-Matched Landing Page (Lesson 02)
Build a page that sets its theme automatically from `prefers-color-scheme` on load, and updates live if the OS setting changes while the page is open.

## Exercise 3 — Sepia Reading Mode (Lesson 03)
Define a custom `data-bs-theme="sepia"` mode with overridden background, text, and primary color variables, applied to a sample article card.

## Exercise 4 — Full Persisted Toggler (Lesson 04)
Build the complete Light/Dark/Auto button group with `localStorage` persistence and a flash-avoiding head script.

## Challenge — Themed Dashboard
Combine all four lessons: a dashboard that respects system preference by default, offers a full toggler, persists the choice, and includes one custom third mode as an additional toggle option.
