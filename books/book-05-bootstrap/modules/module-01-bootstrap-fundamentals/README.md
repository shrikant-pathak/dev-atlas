# Module 01 — Bootstrap Fundamentals

## Overview
This module introduces Bootstrap 5 — what it is, why teams use a framework instead of hand-written CSS, and how to get it running in a real project. By the end, you'll understand Bootstrap's two-layer architecture (CSS + JS), have a working starter template, and know both ways to control interactive components.

## Lessons
1. **What is Bootstrap & Why Use It** — history, problem it solves, mobile-first philosophy, comparison to hand-written CSS
2. **CDN vs npm Setup** — both installation methods, bundle vs plain JS file
3. **Project Structure & Starter Template** — the official starter template annotated, multi-page project organization
4. **Reboot & Browser Support** — Bootstrap's CSS normalization layer, supported browsers/platforms
5. **Bootstrap's JavaScript: Data Attributes vs Programmatic API** — both ways to control components, manual initialization, component events

## Prerequisites
Book 02 — HTML, Book 03 — CSS, and Book 04 — JavaScript (DOM basics, event listeners).

## What You Should Be Able to Do After This Module
- Explain what Bootstrap is and why a team would choose it over hand-written CSS
- Set up a new project with Bootstrap via either CDN or npm
- Correctly structure a multi-page project's HTML, CSS, and JS files
- Understand what Reboot changes and which browsers Bootstrap 5 supports
- Trigger a Bootstrap component both with data attributes and with JavaScript
