# Module 03 Cheatsheet — Typography & Content

## Headings
```html
<h1 class="display-1">...</h1>  <!-- display-1 through display-6 -->
```

## Text Utilities
```html
text-start / text-center / text-end
text-lowercase / text-uppercase / text-capitalize
fw-bold / fw-normal / fw-light
fst-italic
```

## Lead & Inline Helpers
```html
<p class="lead">...</p>
<mark>...</mark>  <del>...</del>  <ins>...</ins>  <small>...</small>
```

## Lists
```html
<ul class="list-unstyled">...</ul>
<ul class="list-inline"><li class="list-inline-item">...</li></ul>
```

## Images
```html
<img class="img-fluid">
<img class="img-fluid rounded">
<img class="img-fluid rounded-circle">
<img class="img-thumbnail">
<img class="rounded float-start me-3">
<img class="rounded mx-auto d-block">
```

## Tables
```html
<table class="table table-striped table-hover table-bordered table-sm">
<tr class="table-success">...
<div class="table-responsive">...</div>
```

## Figures & Code
```html
<figure class="figure">
  <img class="figure-img img-fluid rounded">
  <figcaption class="figure-caption">...</figcaption>
</figure>
<code>...</code>  <pre><code>...</code></pre>  <kbd>...</kbd>  <samp>...</samp>
```

## Hero Recipe
```html
<div class="container-fluid bg-light py-5">
  <div class="container">
    <h1 class="display-4 fw-bold">...</h1>
    <p class="lead">...</p>
    <a class="btn btn-primary btn-lg">...</a>
  </div>
</div>
```
