# Module 03 — Typography & Content

## Overview
This module covers Bootstrap's typography system, responsive font scaling, and content presentation: images, tables, figures, code display, and the classic "hero section" pattern rebuilt from utility classes.

## Lessons
1. **Typography Basics** — headings, display headings, text alignment/transform/weight, lead paragraphs, inline helpers, blockquotes, lists
2. **Responsive Font Sizes (RFS)** — Bootstrap's fluid font-scaling Sass tool, applied automatically to display headings
3. **Images** — `.img-fluid`, shape utilities, alignment
4. **Tables** — striping, borders, hover, contextual colors, responsive tables
5. **Figures & Code** — `<figure>`/`<figcaption>`, inline code, code blocks, `<kbd>`, `<samp>`
6. **Jumbotron/Hero Recipe** — why the dedicated component was removed, rebuilding it from utilities

## Prerequisites
Module 01 — Bootstrap Fundamentals, Module 02 — Layout & Grid System, and Book 02/03 (semantic HTML elements, typography and box model fundamentals).

## What You Should Be Able to Do After This Module
- Style headings, body text, and inline content the "Bootstrap way"
- Explain how RFS keeps large headings readable across screen sizes
- Make any image responsive and shape it appropriately
- Build a styled, accessible, responsive table
- Display code samples and keyboard shortcuts correctly
- Build a custom hero/banner section entirely from utility classes
