# Module 03 Exercises — Typography & Content

## Exercise 1 — Typography Showcase
Build a page demonstrating every heading level, a `.display-1` through `.display-6`, and at least four text utility classes (alignment, transform, weight).

## Exercise 2 — Lead Paragraph
Build a small article header: an `<h2>`, followed by a `.lead` paragraph, followed by two regular paragraphs.

## Exercise 3 — RFS Observation
Add a `.display-1` heading to a page and resize your browser from full width down to a narrow mobile width. Write down what you observe about how the font size changes.

## Exercise 4 — Responsive Image Gallery
Build a 3-image row using `.img-fluid`, with one image styled `.rounded-circle`, one `.rounded`, and one `.img-thumbnail`.

## Exercise 5 — Floated Image with Text Wrap
Float an image to the left of a paragraph of text using `.float-start`, adding appropriate margin so the text doesn't touch the image.

## Exercise 6 — Styled Data Table
Build a table of at least 4 rows and 3 columns showing sample data (e.g., a class schedule or expense list). Apply striping, hover, and borders.

## Exercise 7 — Contextual Table Rows
In your table from Exercise 6, add one row with `.table-success` and one with `.table-danger` to represent "approved" and "rejected" states.

## Exercise 8 — Responsive Table
Build a table with 6+ columns of data and wrap it in `.table-responsive`. Test it on a narrow viewport to confirm it scrolls instead of breaking the layout.

## Exercise 9 — Code Documentation Snippet
Build a small "how to install" documentation block using `<pre><code>`, `<kbd>` for a keyboard shortcut, and `<samp>` for expected output.

## Exercise 10 — Build a Hero Section
From scratch, build a full-width hero section with a background color, a `.display-4` heading, a `.lead` paragraph, and a call-to-action button — using only utility classes, no custom CSS.
