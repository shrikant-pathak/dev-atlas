# Module 09: Utility Classes, Helpers and Accessibility

## Overview
This module formalizes utility systems used piecemeal since Module 02 (flex, display, position), introduces newer helper utilities (object-fit, ratio, stacks, stretched-link, truncation), and closes with a dedicated accessibility lesson that consolidates every ARIA/attribute pattern used across the book so far.

## Lessons
1. **Flex Utilities** — `.d-flex`, direction, justify/align, wrap, grow/shrink/fill
2. **Display and Position Utilities** — `.d-*` family, responsive show/hide, `.position-*`, edge + translate positioning
3. **Object Fit and Ratio** — `.object-fit-*`, `.ratio`/`.ratio-*`, custom aspect ratios
4. **Stacks and Stretched Link** — `.vstack`/`.hstack`, `.stretched-link`, why not to wrap a whole card in `<a>`
5. **Text Truncation and Visually Hidden** — `.text-truncate`, flex truncation gotcha, full `.visually-hidden` recap
6. **Clearfix and Vertical Rule** — `.clearfix` for floats, `.vr` as a flex-aware divider
7. **Colored Links and Icon Link** — `.link-{color}`, link opacity/underline utilities, `.icon-link`
8. **Focus Ring** — `.focus-ring`, why removing focus outlines is harmful, when it's your responsibility
9. **Accessibility in Bootstrap** — the seven recurring accessibility patterns from Modules 05–09, manual vs. automated testing

## Prerequisites
- Every prior module in Book 05 — this module explicitly revisits and consolidates utilities and accessibility attributes first introduced across Modules 02 and 05–08 (flex from the grid module, ARIA patterns from forms/components)

## What's Next
Module 10 (Dark Mode and Color Modes) builds directly on the CSS variable customization concepts touched on in Module 04 and this module's ratio/link utilities, applying them to full light/dark theme switching.
