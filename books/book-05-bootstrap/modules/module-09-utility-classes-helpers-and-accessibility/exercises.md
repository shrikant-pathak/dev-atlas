# Module 09 Exercises

## Exercise 1 — Responsive Card Footer (Lesson 01)
Build a card footer that stacks vertically on mobile and becomes a horizontal row with space-between at `sm`, using flex utilities only.

## Exercise 2 — Show/Hide Sidebar (Lesson 02)
Build a layout with a sidebar hidden below `lg` and a floating "Sale" badge on a card using position + translate-middle.

## Exercise 3 — Responsive Video + Image Grid (Lesson 03)
Build a 16:9 embedded video using `.ratio` and a 3-image grid using `.object-fit-cover` at a fixed height.

## Exercise 4 — Clickable Article Card (Lesson 04)
Build an article preview card using `.stretched-link` for the title, with a separate independently-clickable "bookmark" icon button that still works.

## Exercise 5 — Truncated Notification List (Lesson 05)
Build a list of 3 notifications with long titles that truncate correctly inside a flex row alongside a fixed-width badge.

## Exercise 6 — Floated Bio with Link Row (Lesson 06)
Build a floated-avatar bio block using `.clearfix`, plus a footer link row separated by `.vr`.

## Exercise 7 — Styled Read-More Link (Lesson 07)
Build an `.icon-link` "Read more" link with underline-on-hover and a theme-colored `.link-{color}`.

## Exercise 8 — Custom Focusable Card (Lesson 08)
Build a `tabindex="0"` custom interactive element with a properly colored `.focus-ring`.

## Exercise 9 — Accessibility Audit (Lesson 09)
Pick any component from Modules 06–08 you've already built and annotate it, identifying which of the seven accessibility patterns each attribute on it belongs to.

## Challenge — Accessible Dashboard Widget
Combine all nine lessons: a flex-laid-out widget header, a responsive ratio-constrained chart placeholder, a stretched-link card title, a truncated subtitle, a clearfix'd floated icon, an icon-link footer action, and a custom focus-ring on one non-native interactive element.
