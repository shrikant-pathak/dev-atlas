# Module 08 Exercises

## Exercise 1 — Confirmation Modal (Lesson 01)
Build a centered, static-backdrop delete-confirmation modal with Cancel/Delete buttons.

## Exercise 2 — FAQ Accordion (Lesson 02)
Build a 4-item FAQ accordion with single-open behavior.

## Exercise 3 — Show More Panel (Lesson 03)
Build a "Show more" text reveal using plain `.collapse` (not an accordion).

## Exercise 4 — Image Gallery Carousel (Lesson 04)
Build a 3-slide carousel with controls, indicators, and captions, with no forced autoplay.

## Exercise 5 — Icon Tooltips (Lesson 05)
Add tooltips to 3 icon-only buttons, each with a different placement, and write the JS initialization.

## Exercise 6 — Help Popover (Lesson 06)
Build a form field with a focus-triggered help popover explaining a validation rule.

## Exercise 7 — Stacked Toasts (Lesson 07)
Build a toast container in the bottom-right with 2 toasts (one persistent, one auto-hiding after 3s).

## Exercise 8 — Docs Sidebar Scrollspy (Lesson 08)
Build a 3-section scrollable doc page with a scrollspy-linked sidebar nav.

## Exercise 9 — Loading Button (Lesson 09)
Build a submit button that swaps to a spinner + "Submitting..." text on click, using `addEventListener`.

## Challenge — Notification-Driven Dashboard
Combine all nine lessons: a dashboard with a collapsible sidebar section (accordion), a modal for settings, tooltips on icon buttons, a toast triggered on save, and a loading spinner on the save button while the toast is pending.
