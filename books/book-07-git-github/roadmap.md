# 🗺️ Book 07 Roadmap – Git & GitHub

> From your first commit to GitHub Actions, security, AI-assisted workflows and certification-ready mastery — everything you need to work with Git and GitHub professionally, in one book.

---

# 📚 Course Information

**Difficulty:** Beginner to Advanced

**Prerequisites:** Book 01 (Foundations – terminal basics); Book 04 (JavaScript) recommended for the Actions, Husky and npm lessons

**Estimated Duration:** 14–16 weeks

**Projects:** 1 capstone (fork → pull request → CI → release) plus hands-on labs in every module

**Exercises:** 15 module exercise sets

**Interview Questions:** 15 module question sets plus a dedicated interview-preparation lesson
