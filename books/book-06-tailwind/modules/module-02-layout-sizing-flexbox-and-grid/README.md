# Module 02 — Layout, Sizing, Flexbox & Grid

## Overview
This module covers Tailwind's complete layout toolkit: display and visibility control, spacing (padding/margin/gap), sizing (width/height/min/max), positioning and stacking, overflow and media fitting, and both of CSS's layout models — Flexbox (one-dimensional) and Grid (two-dimensional). It closes with a practical recipes lesson combining everything into the patterns you'll build constantly: centering, sticky footers, and holy-grail layouts.

## Lessons
1. **Display and Visibility** — display utilities, `hidden` vs `invisible`, `sr-only`
2. **Padding, Margin, and Space Between** — the spacing scale, directional shorthands, `space-x-*`/`space-y-*`
3. **Width, Height, and Size** — fixed/fractional/viewport sizing, dynamic viewport units, the v4 `size-*` utility
4. **Min/Max Sizing and Container** — flexible size boundaries and the `container` class
5. **Position, Inset, and Z-Index** — positioning modes, offsets, logical `start-*`/`end-*`, stacking order
6. **Overflow, Aspect Ratio, and Object Fit** — content clipping/scrolling, fixed ratios, media fitting
7. **Flexbox Basics** — enabling flex, direction, wrapping
8. **Flex Sizing and Order** — grow/shrink/basis shorthands, visual reordering
9. **Alignment, Justify, and Gap** — main/cross axis alignment, per-item overrides, spacing
10. **Grid Basics and Tracks** — enabling grid, defining columns/rows, auto-placement
11. **Grid Spans, Placement, and Subgrid** — spanning tracks, exact placement, nested grid alignment
12. **Centering and Common Layout Recipes** — centering patterns, sticky footer, holy grail, modal overlays

## Learning Outcomes
By the end of this module, you will be able to:
- Build any common layout structure (sidebar, grid, centered content, sticky footer) using Tailwind utilities alone
- Choose correctly between Flexbox and Grid for a given layout problem
- Apply consistent spacing and sizing using Tailwind's shared scale
- Control stacking order and positioning for overlays, dropdowns, and sticky elements

Module 01 (Tailwind Fundamentals & Setup) and Book 03 (CSS) — particularly the box model, Flexbox, and CSS Grid chapters.
