# Module 04 — Borders, Shadows & Visual Effects

## Overview
This module covers Tailwind's visual-polish toolkit: borders and rounded corners, accessible focus indicators (outline vs. ring), elevation via box and text shadows, opacity and blend modes, filters, the newer mask and backdrop-filter utilities, and both 2D and 3D transforms, paired with transitions for smooth, animated state changes.

## Lessons
1. **Borders, Radius, and Dividers** — border width/color/style, rounded corners, `divide-*` sibling dividers
2. **Outline and Ring** — accessible focus states, box-shadow-based rings, the v4 ring-width breaking change
3. **Box and Text Shadows** — the elevation scale, colored shadows, v4's new `text-shadow-*`
4. **Opacity, Blend Modes, and Filters** — element opacity vs. color opacity, blend modes, filter effects
5. **Masks and Backdrop Effects** — frosted-glass backdrop filters, v4's new gradient-based mask utilities
6. **Transitions and Easing** — smooth animated state changes, duration, easing curves, delays
7. **Transforms (2D and 3D)** — scale/rotate/translate/skew, and v4's new native 3D transform utilities

## Learning Outcomes
By the end of this module, you will be able to:
- Build polished UI components with borders, shadows, and rounded corners
- Choose correctly between outline and ring for focus states, and migrate v3 `ring` usage safely
- Apply modern visual effects (frosted glass, edge fades, 3D tilts) using current-generation Tailwind utilities
- Add smooth, natural-feeling transitions to interactive state changes

## Prerequisites
Module 01 (Fundamentals & Setup), Module 02 (Layout), and Module 03 (Typography & Color) — this module builds directly on the shared color palette and opacity syntax from Module 03.
