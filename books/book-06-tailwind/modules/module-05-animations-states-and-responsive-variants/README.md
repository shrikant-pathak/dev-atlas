# Module 05 — Animations, States & Responsive Variants

> Make interfaces feel alive: motion, interaction states, and layouts that adapt — all with utilities and variants.

## 📌 Overview

In Module 04 you learned to style the *static* look of an element. This module is about how it **behaves**: how it moves, how it reacts to hover, focus and state, and how it adapts to screens and containers. The unifying idea is the **variant** — a prefix that makes any utility conditional.

## 🎯 Prerequisites

- Book 03 — CSS (pseudo-classes, media queries, keyframes, container queries)
- Book 05 — Bootstrap (for the responsive-breakpoint comparison)
- Book 06, Modules 01–04 (setup, layout, typography, effects, transitions)

## ✅ What you'll be able to do

- Add purposeful, accessible motion and respect `prefers-reduced-motion`
- Style any interactive state without writing custom CSS
- Build toggles, tabs, accordions and selectable cards with **no JavaScript state for styling**
- Drive styles from `aria-*` and `data-*` attributes (the bridge to Radix/Headless UI)
- Build layouts that adapt to the viewport **and** to their container
