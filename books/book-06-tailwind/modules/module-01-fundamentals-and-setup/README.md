# Module 01 — Tailwind Fundamentals & Setup

## Overview
This module introduces Tailwind CSS v4's core philosophy — utility-first styling — and gets a working project running. You'll learn what makes Tailwind different from traditional CSS (Book 03) and component frameworks like Bootstrap (Book 05), install it using the method that fits your project, understand what the single CSS entry point actually does, learn how Tailwind generates CSS on demand, and set up your editor for fast, error-resistant Tailwind development.

## Lessons
1. **Intro to Tailwind and Utility-First CSS** — the utility-first philosophy, compared against traditional CSS and Bootstrap
2. **Installing Tailwind (Vite, CLI, and CDN)** — four installation paths and when to use each
3. **CSS Entry Point and Project Structure** — what `@import "tailwindcss"` pulls in, and Preflight's base reset
4. **How Tailwind Generates CSS** — on-demand generation, the Oxide engine, automatic content detection, and the dynamic class name pitfall
5. **Editor Setup, IntelliSense, and Prettier** — the official IntelliSense extension and automatic class sorting

## Learning Outcomes
By the end of this module, you will be able to:
- Explain the utility-first approach and when it's the right fit for a project
- Install Tailwind CSS v4 in a Vite, CLI, or PostCSS-based project
- Understand what Preflight does and why headings render unstyled by default
- Explain how on-demand CSS generation works and avoid the dynamic class name pitfall
- Set up IntelliSense and automatic Prettier class sorting for a productive workflow

## Prerequisites
Book 02 (HTML) and Book 03 (CSS) — comfortable with the box model, semantic HTML, and basic CSS properties. Familiarity with npm (Book 04, Module 09) is helpful for the installation lessons.
