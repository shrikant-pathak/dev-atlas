# Module 03 — Typography & Color System

## Overview
This module covers every text-related utility in Tailwind — font family, size, weight, line-height, letter-spacing, color, alignment, decoration, wrapping, and truncation — along with the official typography plugin for styling raw HTML content. It closes with Tailwind's full color system: the default OKLCH-based palette, opacity control, and gradients.

## Lessons
1. **Font Family, Size, and Weight** — font stacks, the `text-*` scale and its bundled line-heights, weight utilities
2. **Line Height, Letter Spacing, and Tracking** — overriding default leading, letter-spacing for labels and headlines
3. **Text Color, Alignment, and Decoration** — color, logical alignment, styled underlines/strikethroughs
4. **Text Wrap, Truncation, and Line Clamp** — `text-balance`/`text-pretty`, single and multi-line truncation
5. **Lists and the Typography Plugin** — list styling, and `@tailwindcss/typography`'s `prose` class for raw HTML
6. **Web Fonts and Font Features** — loading custom fonts, tabular numbers, antialiasing
7. **Color Palette and OKLCH** — the default palette's shape and v4's OKLCH color space
8. **Text and Background Colors with Opacity** — background color, the slash opacity syntax
9. **Gradients and Background Images** — linear/radial/conic gradients, background image utilities

## Learning Outcomes
By the end of this module, you will be able to:
- Build a complete typographic hierarchy (headings, body, labels) using Tailwind utilities alone
- Style raw, uncontrolled HTML content (Markdown/CMS output) using the typography plugin
- Apply Tailwind's full color system, including transparency and gradients
- Explain why v4's OKLCH-based palette and slash opacity syntax replaced v3's approaches
