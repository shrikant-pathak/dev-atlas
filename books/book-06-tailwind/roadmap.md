# 🗺️ Book 06 Roadmap – Tailwind CSS
> Master utility-first styling with Tailwind CSS v4 — from layout primitives to production-ready design systems.

# 📚 Course Information
**Difficulty:** Beginner to Intermediate
**Prerequisites:** Book 03 (CSS) and Book 02 (HTML) — comfort with the box model, flexbox/grid fundamentals, and semantic HTML
**Estimated Duration:** 8–10 weeks
**Projects:** 2 (design system foundation + capstone landing page/dashboard)
**Exercises:** 9 (one set per module)
**Interview Questions:** 9 (one set per module)
