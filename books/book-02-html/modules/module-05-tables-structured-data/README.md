# Module 05: Tables & Structured Data

> **Book:** Book 02 — HTML
> **Module:** 05 of Book 02

---

## 📌 Module Overview

This module covers HTML tables end to end — correct structure, header/footer grouping, spanning rows and columns, and genuine accessibility (not just visual styling). It closes with the single most important judgment call in this whole topic: knowing when data is genuinely tabular versus when reaching for `<table>` is actually a historical anti-pattern in disguise.

**Difficulty:** 🟡 Intermediate
**Estimated Time:** 6–8 hours (lessons + exercises)
**Prerequisites:** Module 04 — Forms & User Input
