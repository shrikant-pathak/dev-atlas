# Exercise Set — Tables & Structured Data

## Easy
- [ ] Build a basic 3-row, 2-column table listing 2 favorite movies with their release years, including proper `<th>` headers.
- [ ] Add a `<caption>` to the table above titled "My Favorite Movies".
- [ ] Restructure the table using `<thead>` and `<tbody>`.
- [ ] Explain why using `<td>` styled bold with CSS is not equivalent to using `<th>`.

---

## Medium
- [ ] Build a table with a `colspan="2"` header spanning two sub-columns beneath it.
- [ ] Build a table with a `rowspan="2"` cell, correctly adjusting the row below to not duplicate that cell.
- [ ] Add `scope="col"` and `scope="row"` to a simple table with both column and row headers.
- [ ] Identify whether each of the following should be a `<table>` or not, with reasoning: a class schedule, a page's header/sidebar/footer layout, a sports league's standings.

---

## Hard
- [ ] Build a table combining `colspan` and `rowspan` for a grouped-header layout (like a "Region" spanning 2 rows, with a "Products" header spanning 2 columns beneath a top row).
- [ ] Build a complex table using `id`/`headers` instead of `scope`, and explain why `scope` alone would be insufficient for this particular table.
- [ ] Explain, historically, why "tables for layout" was so widespread before being abandoned, and what changed to make it obsolete.

---

## Bonus
- [ ] Research `<colgroup>` and `<col>` (not covered in this module) and explain what they're used for.
