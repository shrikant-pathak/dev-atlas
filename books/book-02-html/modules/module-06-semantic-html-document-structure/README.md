# Module 06: Semantic HTML & Document Structure

> **Book:** Book 02 — HTML
> **Module:** 06 of Book 02

---

## 📌 Module Overview

This module is where every semantic principle from earlier in the book culminates — the full HTML5 vocabulary for structuring an entire page meaningfully: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`. It closes with building one complete, real page layout combining everything, with explicit reasoning for every structural choice.

**Difficulty:** 🟡 Intermediate
**Estimated Time:** 6–8 hours (lessons + exercises)
**Prerequisites:** Module 05 — Tables & Structured Data
