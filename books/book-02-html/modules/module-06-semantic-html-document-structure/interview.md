# Interview Questions — Semantic HTML & Document Structure

## Beginner
- What does "semantic HTML" mean?
- What is "div soup," and why is it a problem?
- What's the difference between `<header>` and `<h1>`?
- How many `<main>` elements should a page have?

## Intermediate
- What's the test for deciding between `<section>` and `<article>`?
- Can `<header>` and `<footer>` appear more than once on a page? Explain.
- Why is wrapping primary site navigation in `<aside>` incorrect, even if it's visually positioned on the side?
- What accessibility benefit does `<main>` provide specifically?

## Advanced
- Explain how a screen reader user benefits concretely from semantic landmarks, compared to a page built entirely from `<div>`s.
- Can an `<article>` contain `<section>` elements? Can a `<section>` contain `<article>` elements? Give an example of each.
- Why might a `<section>` with no heading be a sign of incorrect element choice?
- Walk through how you'd structure a blog homepage using this module's elements, explaining your reasoning for each choice.
