# Exercise Set — Semantic HTML & Document Structure

## Easy
- [ ] Rewrite this "div soup" as semantic HTML: `<div class="header">...</div><div class="nav">...</div><div class="footer">...</div>`.
- [ ] Write a page-level `<header>` containing an `<h1>` and a `<nav>` with 3 links.
- [ ] Explain, in one sentence, the difference between `<section>` and `<article>`.
- [ ] Build a `<details>`/`<summary>` FAQ item.

---

## Medium
- [ ] Build an `<article>` for a blog post with its own `<header>` (title + date) and `<footer>` (tags).
- [ ] Decide whether each belongs in `<section>` or `<article>`, with reasoning: a single product review, a "Customer Reviews" heading grouping several reviews, a full news story.
- [ ] Build a page with exactly one `<main>`, and explain why a second `<main>` would be incorrect.
- [ ] Add an `<aside>` inside an `<article>` containing a genuinely tangential "related reading" list.

---

## Hard
- [ ] Build a complete page skeleton using every element from this module at least once: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>` — with a page-level header/footer AND an article-level header/footer.
- [ ] Find and fix the mistake: a sidebar containing the site's primary navigation menu is wrapped in `<aside>`. Explain why this is wrong and provide the fix.
- [ ] Explain why a `<section>` with no heading is often a sign that `<div>` was actually the correct choice.

---

## Bonus
- [ ] Research how screen readers announce "landmarks" (header, nav, main, footer) and explain, in your own words, why this matters for real users navigating a page without sight.
