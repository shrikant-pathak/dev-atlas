# Exercise Set — HTML5 APIs & Advanced Features

## Easy
- [ ] Write a `<canvas>` element with `width="500"` and `height="300"`.
- [ ] Write an `<svg>` containing a single red rectangle.
- [ ] Mark a `<div>` as draggable using the correct attribute.
- [ ] Explain, in one sentence, the difference between localStorage and sessionStorage.

---

## Medium
- [ ] Explain why SVG icons are generally preferred over PNG icon images on modern websites.
- [ ] Write fallback content inside a `<canvas>` element describing a bar chart, for accessibility.
- [ ] Explain why requesting geolocation access immediately on page load is poor UX.
- [ ] Run one of your own HTML files through validator.w3.org and list any errors or warnings it flags.

---

## Hard
- [ ] Compare canvas and SVG for a specific hypothetical project (a simple drawing app) — which would you choose, and why?
- [ ] Explain why Web Storage is generally preferred over cookies for purely client-side data like a UI theme preference.
- [ ] Explain how Web Components conceptually foreshadow what you'll learn in Book 09 (React).
- [ ] Explain the "success callback / error callback" pattern shared by both the Geolocation API and (conceptually) other asynchronous browser APIs.

---

## Bonus
- [ ] Research `customElements.define()` (not covered in depth in this module) and write, in your own words, what the basic process of defining a custom element involves.
