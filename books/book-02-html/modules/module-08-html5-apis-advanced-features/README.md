## 📌 Module Overview

This module previews HTML's more advanced, JavaScript-adjacent native capabilities — canvas and SVG for graphics, Drag & Drop, Web Storage, Geolocation, and a conceptual introduction to Web Components. Full mastery of these requires JavaScript (Book 04) and beyond, but understanding what exists and why now means none of it will feel unfamiliar later. It closes with a genuinely practical tool: the W3C HTML validator.

**Difficulty:** 🟡 Intermediate → 🔴 Advanced
**Estimated Time:** 6–8 hours (lessons + exercises)
**Prerequisites:** Module 07 — Accessibility (a11y) & SEO Fundamentals
