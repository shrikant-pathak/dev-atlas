# Interview Questions — HTML5 APIs & Advanced Features

## Beginner
- What is `<canvas>` used for?
- What's the difference between SVG and a regular image file (PNG/JPEG)?
- What attribute makes an HTML element draggable?
- What is localStorage used for?

## Intermediate
- Why does canvas content require manual fallback content for accessibility, while SVG doesn't (as much)?
- What's the difference between localStorage and sessionStorage?
- Why does the Geolocation API always require explicit user permission?
- What's the difference between how cookies and Web Storage interact with the server?

## Advanced
- Compare canvas and SVG in terms of performance for a large number of elements/shapes.
- Explain why requesting geolocation on page load (rather than on user action) is considered poor practice.
- What are Web Components, and how do they conceptually relate to frameworks like React?
- Why does HTML validation matter even though browsers automatically "fix" malformed markup?
