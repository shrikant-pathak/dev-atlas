# Interview Questions — Accessibility & SEO Fundamentals

## Beginner
- What does "web accessibility" mean?
- What is ARIA, and when should you use it?
- What does the `<meta name="description">` tag affect?
- What is a favicon?

## Intermediate
- What is the "First Rule of ARIA"?
- How do screen reader users navigate a page using headings and landmarks?
- What problem do Open Graph tags solve?
- Why does descriptive anchor text matter for both SEO and accessibility?

## Advanced
- Explain what structured data (Schema.org/JSON-LD) is, and how it differs from semantic HTML.
- What are "rich results," and how does structured data enable them?
- Walk through the difference between `aria-label`, `aria-labelledby`, and `aria-describedby`.
- Beyond HTML structure, name other major factors that affect real-world SEO.
