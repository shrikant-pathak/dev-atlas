# Exercise Set — Accessibility & SEO Fundamentals

## Easy
- [ ] Add `aria-label` to an icon-only close button (✕).
- [ ] Write a `<meta name="description">` tag for a page about "Learning HTML."
- [ ] Explain why "click here" is a poor choice for anchor text.
- [ ] List the four major categories of disability affecting web use.

---

## Medium
- [ ] Rewrite this ARIA misuse using native HTML instead: `<div role="button" tabindex="0" onclick="submit()">Submit</div>`.
- [ ] Write Open Graph tags (title, description, image, type) for a blog post titled "Semantic HTML Explained".
- [ ] Explain how heading navigation works for screen reader users, and why skipping heading levels breaks it.
- [ ] Add `aria-describedby` to a password input, linking it to a hint paragraph.

---

## Hard
- [ ] Write a basic JSON-LD structured data block for an `Article` with headline, author, and datePublished.
- [ ] Run a Lighthouse Accessibility audit (Chrome DevTools) on any real webpage and list 3 issues it flags.
- [ ] Explain the difference between `aria-label` and `aria-labelledby`, with a concrete example of when each is appropriate.
- [ ] Build a complete `<head>` for a page, including all SEO/social meta tags from this module.

---

## Bonus
- [ ] Try navigating a real website using only your keyboard (Tab, Enter, no mouse) and note any places where focus gets lost or unclear.
