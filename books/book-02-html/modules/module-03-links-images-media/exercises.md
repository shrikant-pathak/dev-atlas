# Exercise Set — Links, Images & Media

## Easy
- [ ] Write a relative link from `index.html` to `pages/about.html`.
- [ ] Write an external link to `https://developer.mozilla.org` that opens in a new tab safely.
- [ ] Add an `<img>` with meaningful alt text describing a sunset over mountains.
- [ ] Write an in-page anchor link that jumps to a section with `id="contact"`.

---

## Medium
- [ ] Given the structure `project/pages/blog/post.html` and `project/images/logo.png`, write the correct relative path from `post.html` to the logo.
- [ ] Build a `<figure>` with an image and caption describing a chart.
- [ ] Write a `<video>` element with two `<source>` formats, `controls`, and a `poster` image.
- [ ] Explain, in your own words, why `srcset` is better than always using one large image file.

---

## Hard
- [ ] Write a `srcset` + `sizes` example serving 3 different image widths, with reasoning for your breakpoints.
- [ ] Embed a YouTube video using `<iframe>` with a proper `title`, `loading="lazy"`, and explain what `sandbox` would add.
- [ ] Explain the "tabnabbing" security risk and how `rel="noopener noreferrer"` prevents it.
- [ ] Build a small navigation menu with `<nav><ul>` containing 3 links: one internal, one external (safe), one in-page anchor.

---

## Bonus
- [ ] Research the `<embed>` and `<object>` elements (not covered in this module) and explain how they differ from `<iframe>`.
