> **Book:** Book 02 — HTML

## 📌 Module Overview

This module covers everything involved in connecting pages together and embedding rich media — links (internal, external, secure), file paths, images (with real accessibility depth on `alt` text), responsive images for different devices, native audio/video, and embedding third-party content safely via iframes. By the end, you can build a page that links, points, and embeds correctly and securely.

**Difficulty:** ⭐ Beginner → 🟡 Intermediate
**Estimated Time:** 7–9 hours (lessons + exercises)
**Prerequisites:** Module 02 — Text & Content Elements
