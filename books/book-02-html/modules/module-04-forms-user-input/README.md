## 📌 Module Overview

Forms are how the web actually collects information — logins, signups, checkouts, search bars. This module covers the full picture: how forms submit data (GET vs. POST), the complete range of HTML5 input types, correctly labeling every field for accessibility, buttons (and the classic accidental-submit bug), dropdowns and textareas, and built-in validation — including the critical distinction between client-side convenience and real server-side security.

**Difficulty:** 🟡 Intermediate
**Estimated Time:** 8–10 hours (lessons + exercises)
**Prerequisites:** Module 03 — Links, Images & Media
