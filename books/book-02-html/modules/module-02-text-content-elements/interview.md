# Interview Questions — Text & Content Elements

## Beginner
- Why should you never skip heading levels (e.g., `<h1>` straight to `<h3>`)?
- What's the difference between `<b>` and `<strong>`?
- What's the difference between `<ul>` and `<ol>`?
- What does `<blockquote>` represent?

## Intermediate
- What is a description list (`<dl>`) used for, and give a real-world example.
- What's the difference between the `cite` attribute and the `<cite>` element?
- Why does HTML collapse whitespace by default, and how does `<pre>` override this?
- What's the purpose of the `datetime` attribute on `<time>`?

## Advanced
- Explain how heading hierarchy affects both SEO and accessibility, concretely.
- Why is `<mark>` considered semantic rather than purely visual, unlike using CSS to highlight text?
- When would `<hr>` be semantically incorrect to use, even if you want a visual dividing line?
- Explain the difference between `<code>`, `<kbd>`, and `<samp>`, with an example of when each is appropriate.
