# Exercise Set — Text & Content Elements

## Easy
- [ ] Write a correctly nested heading structure for a page about "Web Development" with two major sections and one subsection under each.
- [ ] Write a sentence using `<strong>` correctly (for genuine importance) and a separate sentence using `<b>` correctly (purely visual).
- [ ] Create an unordered list of 3 favorite foods and an ordered list of 3 steps to make tea.
- [ ] Mark up the abbreviation "HTML" using `<abbr>` with its full expansion as a tooltip.

---

## Medium
- [ ] Build a description list (`<dl>`) glossary with at least 3 terms and definitions.
- [ ] Write a short blockquote with a `cite` attribute and a visible `` element crediting the source below it.
- [ ] Create a nested list showing "Frontend" and "Backend" as top-level items, each with 3 nested technology names.
- [ ] Mark up a code example using `<pre><code>` for a 3-line JavaScript function.

---

## Hard
- [ ] Build a small blog post structure using at least 6 different elements from this module (headings, paragraphs, lists, semantic text elements, a quote).
- [ ] Explain why using `<h3>` instead of `<h1>` just because "it looks the right size" is a genuine accessibility problem, not just a style preference.
- [ ] Write HTML for an address block using `<address>` and `<br>` correctly, then explain why `<br>` is appropriate here but wouldn't be for paragraph spacing.

---

## Bonus
- [ ] Research the `<figure>` and `<figcaption>` elements (not covered in this module) and explain what they're likely used for, based on the semantic patterns you've learned.
