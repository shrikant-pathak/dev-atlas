# Interview Questions — Real-World Project & Best Practices

## Beginner
- What naming convention do HTML classes and IDs conventionally use?
- Why does consistent indentation matter in a codebase?
- What tool can automatically format your HTML consistently?
- What is code review?

## Intermediate
- Why can't plain HTML share a header/footer across multiple pages without duplication?
- Name three common HTML mistakes and explain why each one matters concretely.
- What's a sensible file structure for a multi-page site with a blog section?
- Why should you validate HTML with a tool like the W3C Validator, even if the page looks correct in the browser?

## Advanced
- Walk through your process for reviewing an HTML page against a checklist before considering it "done."
- What later technologies (covered in future books) solve HTML's lack of native templating, and how do they relate conceptually?
- If you inherited a real project with inconsistent naming conventions and indentation, how would you approach fixing it without breaking anything?
- Explain how the concepts in this module tie together everything from earlier modules in Book 02.
