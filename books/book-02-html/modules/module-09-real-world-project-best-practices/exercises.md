# Exercise Set — Real-World Project & Best Practices

## Easy
- [ ] Rewrite `<div CLASS='UserCard'>` following correct modern style conventions (lowercase, kebab-case, double quotes).
- [ ] Sketch (on paper or in a text file) the file structure for a 4-page site: home, about, services, contact.
- [ ] Identify the mistake in `<input type="email" placeholder="Email">` and fix it.
- [ ] List 3 items from the Lesson 04 checklist you'd check first on any new page.

---

## Medium
- [ ] Explain, in your own words, why plain HTML can't share a `<header>` across multiple pages without duplication.
- [ ] Build the shared `<nav>` for a 3-page site, with correct relative paths from each page's perspective.
- [ ] Take a piece of HTML with 3 intentional mistakes (write it yourself, based on Lesson 03) and have a study partner (or yourself, later) find and fix them.
- [ ] Run any HTML file through the W3C Validator and report the results.

---

## Hard
- [ ] Begin the Lesson 05 capstone project: build `index.html` fully, applying the complete checklist from Lesson 04.
- [ ] Complete all three pages of the capstone project (`index.html`, `about.html`, `contact.html`).
- [ ] Run your finished capstone project through the full Lesson 04 checklist and the W3C Validator, fixing any issues found.

---

## Bonus
- [ ] Read Google's HTML/CSS Style Guide (search for it) and note 2 conventions it recommends that weren't covered in Lesson 01.
