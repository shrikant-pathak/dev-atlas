## 📌 Module Overview

This is where you start writing real, structural web technology. This module covers exactly what HTML is (and isn't), how a document is put together from the ground up, the precise vocabulary of tags/elements/attributes, the block-vs-inline layout model that CSS will build on top of, and the small but essential details (classes, IDs, entities) you'll use in literally every HTML file you ever write.

**Difficulty:** ⭐ Beginner
**Estimated Time:** 6–8 hours (lessons + exercises)
**Prerequisites:** Book 01 — Foundations (all modules)
